### Bug

In `crates/victory-hle/src/modules/apu.rs` (`process`):

```rust
let out = unsafe { std::slice::from_raw_parts_mut(output.cast::<f32>(), frames * channels) };
```

`command.output` is a `*mut u8` from a `#[repr(C, packed)]` title `Process` command with no 4-byte alignment guarantee. Calling `slice::from_raw_parts_mut` on `output.cast::<f32>()` with any non-4-byte-aligned pointer (even when `frames == 0`) is Rust undefined behavior and triggers an immediate non-unwinding debug panic / abort (`0xc0000409`) across `extern "system" fn XApuEnqueueCommand`.

Two minor guards in the same module were also tightened:
- `XApuConnect` did not check for a null handle from `CreateEventW` when `RESULT_EVENT` was requested (returning `S_OK` with a null `result_event` instead of freeing `memory` and returning `E_OUTOFMEMORY`).
- `ACTIVATE` called `OpusDecoder::new(48_000, channels as usize)` before checking `(1..=2).contains(&channels)`.

### Fix

- Write decoded PCM samples through a byte slice (`std::slice::from_raw_parts_mut(output, bytes)` + `as_chunks_mut::<4>()` + `f32::to_le_bytes()`) only when `bytes > 0`, eliminating alignment UB for both interleaved and `DEINTERLEAVED_OUTPUT` stereo paths.
- Validate `(1..=2).contains(&channels)` before constructing `OpusDecoder`, and deallocate `memory` + return `E_OUTOFMEMORY` if `CreateEventW` returns null.
- Added synthetic regression test `modules::apu::tests::decodes_into_unaligned_output_interleaved_and_deinterleaved` testing unaligned output pointers (both interleaved and deinterleaved stereo, bit-for-bit identical to aligned output), zero-frame decode at a misaligned pointer, and invalid channel counts (`0`, `3`, `u32::MAX`).

### Verification

- **Before fix:** `decodes_into_unaligned_output_interleaved_and_deinterleaved` aborted with `unsafe precondition(s) violated: slice::from_raw_parts_mut requires the pointer to be aligned and non-null` (`0xc0000409`) at `apu.rs:344`.
- **After fix (Windows 11):**
  - `cargo test -p victory-hle`: 95 unit tests + 1 integration test passed, 0 failed.
  - `cargo clippy -p victory-hle --all-targets -- -D warnings`: clean.
  - `cargo check -p victory --features diagnostics`: clean.
  - `rustfmt --edition 2024 --check crates/victory-hle/src/modules/apu.rs`: clean.
  - `cargo xtask policy`: 154 files ok.
