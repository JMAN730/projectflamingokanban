## Original body

First run report: RTX A4500 on a Shadow PC (cloud Windows machine) — menus/intro at a clean 30 fps, world held ~80 s (1 fps degrading to 0.3 fps) before a GPU device removed (DXGI 0x887A0006, right after a 3818 ms submission of 26 lists), without TdrDelay.

Adding a data point from an untested hardware combination: NVIDIA GPU + cloud PC. Happy to run further diagnostics on request.

Environment

Machine: Shadow PC (cloud Windows desktop, x64)

CPU: AMD EPYC 7543P 32-core (Zen 3, AVX2)

GPU: NVIDIA RTX A4500 (Ampere, DirectX 12 Ultimate, SM 6.6, mesh shaders) — driver up to date

RAM: 28 GB, paging file increased to 43–85 GB (required to clear Windows error 1455 at startup)

OS: Windows 10/11 x64 with all updates

Build: source snapshot of Nov 24, 2026 (ZIP), cargo build --release -p victory

Run command: target\release\victory.exe run "<game>\scarlett_master.exe" --execute --console series-x

Note: I initially renamed the title executable (GTA VI.exe) — the run only worked after restoring its original file name. Might be worth documenting that the exe file name matters.
