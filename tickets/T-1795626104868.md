## Original body

Pull requests are limited to collaborators on this repository, so this is a fork report instead.

Fork branch: https://github.com/Machad3x/VIctory/tree/claude/gta6-shader-translation-crashes-705550 (55 commits on top of `main` at ffe310e, `cargo test --workspace` passes at the last full run; each commit message explains why).

## What the branch contains

- Host device at the highest feature level the adapter accepts; descriptor fallback of the right kind when a view cannot be created; 4-dword V# from SGPRs; V_DYNAMIC stride from a runtime V#; unmapped SGPRs read as zero; `image_gather4_l`; 64-bit LDS/image atomics; WaveSize/clamp fixes; LDS subword access; lane-mask phis; use-before-def; cube clamp; empty-PSO slot 0x218; direct barycentric VGPRs read as zero.
- Cache and memory: pruned journal, mirrored descriptor-table base, copy-back pool with dedup, eviction of placed textures and loose windows when title memory is remapped.
- Diagnostics: DRED state in the removal report; when the adapter records no breadcrumbs (WARP), the report lists what each submitted list binds.
- A reconciliation commit after merging the waterfall/per-lane-phi work (`heap_handle` gained a `nonuniform` argument, `Structured.other` was dropped while the lane-mask phi join still reads it).

## Observations (not fixes)

- WARP: the world has no mesh shaders there, so about 4100 draws/frame are dropped and the screen is black in game. A build without the `diagnostics` feature ran 14+ min without device removal; with it, WARP died in its own JIT code (a read of 0x0) in the present path.
- RTX 3080 Ti, `VICTORY_GPU_TIMING=1`: a mesh shader takes 1375 ms for 4 groups (`mesh 04b9be3756e8f41c`, pixel `1af4a50c7fb40c97`) and `a26422c01dcf5612` takes 418 ms, then the ~2 s TDR (`0x887A0006`). With `VICTORY_SHADER_LOOP_LIMIT=64` another mesh shader (`89036e16fa081505`) becomes the slow one, so it is not the loop count alone. Same family as #496, #619 and #791. Hypothesis, unverified: a barrier in divergent control flow in the translated mesh shader.
- A real-GPU run also logs `E_INVALIDARG` (0x80070057) for 2560x1440 textures (formats 86 and 115) and "host view heap capped at 1000000".

Happy to split the branch into separate PRs if collaborator access is granted.
