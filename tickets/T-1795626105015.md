## Original body

AI-assisted testing by Doffi4 on main at `ffe310eb2098e52169f4c44db5ffdabf43a72622`. This is a Windows synthetic baseline for the rendering path. No game files were used.

## Environment

- Windows 11 25H2 x64, build 26200.9550, Rust 1.98.1 MSVC
- AMD Radeon 780M, driver 32.0.32029.2010
- NVIDIA GeForce RTX 5060 Laptop GPU, driver 32.0.16.2101
- WARP as a software control
- Debug builds. The frame test enables the diagnostics feature.

## Results

- Clean checkout, `cargo test --workspace --locked -- --test-threads=1 --show-output`: 338 executed passes, 0 failures, 10 skips (6 ignored, 4 differential checks returned early without the console compiler). Both PE/HLE probe tests and the asset-policy test passed.
- Explicit adapter runs: all 5 waterfall and all 13 VALU tests passed on each of the Radeon, the RTX and WARP. No skips in these runs.
- D3D12.X proxy smoke test: a 384×216 render target cleared to magenta, submitted, then reused after `ResetX`. The second submission uses `DrawInstanced` to draw a green full-screen triangle via `ExecuteX`. Host draw count increased by one, and readback checked every RGBA pixel against the expected value on both frames. An initial control using a prebuilt host PSO passed on all three adapters.
- The final test feeds two hand-authored Xbox-style shader containers into the standard pipeline-state stream and exercises VIctory's translation and worker PSO creation. Cold and warm runs were separate processes with a dedicated disk cache per adapter. All six runs passed, with zero skips and zero failures. Each cold run recorded 0 hits / 2 misses and each warm run recorded 2 hits / 0 misses for the shader translation cache.

[Reproducer, HLSL, generator and local test patches](https://gist.github.com/Doffi4/3d40d85fd2532913c59ad6b5eeaebdcf)

The result covers offscreen rendering and shader translation caching. Swap-chain presentation, the driver PSO cache, parallel test stability, menus and world entry were outside this run. The next check is to send the same synthetic target through PresentX and verify swap-chain output.
