## Original body

A test report from a Windows 10 + NVIDIA host, since the README lists only one tested
machine (Windows 11, AMD RX 6700 XT). Related: #598, #175, #626, #597.

## Environment
- Windows 10 22H2 (10.0.19045.6456)
- NVIDIA GeForce RTX 3060 12 GB, driver 32.0.16.1656 (616.56)
- 24 GB RAM
- Title 7952987A, Game Version 930.048.020, console series-x
- Builds: release and diag

## 1. main @ ffe310e (in-box D3D12 runtime): crash, same as #598
- Every root signature refused: "Unsupported bit-flag set (root signature flags c01)",
  then "host root signature refused (0x80070057)"
- Nothing drawn (0 drawn per frame in every frame)
- Crash at title+0xb5a5f8 (read 0x68) ~2 s after XUserAddAsync, 5 of 5 runs
- Also tried: PR #702 (DXR backend): same crash. Empty D:\decorations\presets and
  \presetgroups on the host (the last paths the title probes before the fault): same crash.

## 2. PR #626: does not help on this host
The new fallback is logged ("runtime rejected directly-indexed flags"), but the pipelines
are still refused (0x80070057) and the crash at +0xb5a5f8 is unchanged.

## 3. PR #175 + `cargo xtask agility` (1.620.2): crash fixed
Branch at <hash>. `victory config` reports `D3D12Core.dll (version 620)`.
- No root signatures refused, 0 draws dropped in the menus
- Intro video, first-boot screens (accessibility, language, settings, legal) and
  the loading screen artwork all render, 30 fps
- No crash after XUserAddAsync
- The title loads story000 (~7 min on this machine) and enters the world

## 4. World entry: GPU hang, as in #597
- First world frames: 0.1 fps (8432 ms/frame), 498 draws/frame, 832 dropped
  without a host pipeline
- ~6 s later: "host GPU device removed after a submission of 25 lists; no breadcrumbs",
  reason 0x887A0006 (DEVICE_HUNG)
- Before the hang: 83 shaders "do not translate" (mostly compute) and 29 compute
  pipelines refused with E_INVALIDARG

## Other notes
- At boot, "method not implemented" on device slots 0x218 and 0x1c8 (menus keep working)
- Two 2560x1440 textures are refused with 0x80070057 (formats 86 and 115, flags 5 and 1)
  when the first-boot screens start; those screens still render

Logs available. I can rerun with a diag build and VICTORY_D3D12_DEBUG=1 /
VICTORY_D3D12_DRED=1 if that would help with #597.
