### Summary
Fixes 4 real bounds-checking and cleanup bugs in `crates/victory-loader/src/windows.rs` (previously 0 unit tests) and adds 13 deterministic synthetic unit tests.

Because external PR creation is currently restricted (`collaborators_only`), the CI-green branch is ready on my fork for cherry-pick / review:
- **Branch**: `geiyiliyabumo/VIctory@test/loader-windows`
- **Commit**: `geiyiliyabumo/VIctory@98b761b` (based on `main` `ffe310e`)

### Bugs Fixed (`crates/victory-loader/src/windows.rs`)
1. **Unchecked IAT writes**: `write_slots` now validates `rva + 8 <= size_of_image` as a batch before any write.
2. **Module leak on TLS redirect failure**: `load` now calls `FreeLibrary` when `tls::redirect` fails after `LoadLibraryExW`.
3. **Out-of-bounds TLS callbacks**: callbacks with RVA `0` or `>= size_of_image` are now logged and skipped instead of executed.
4. **Out-of-image `DllMain` / entry point**: guarded in both `notify` and `spawn_main`.
