## 1. Host GPU (RTX 3060), `VICTORY_D3D12_WARP` not set
Command:
```
target\diag\victory.exe run S:\GTA6\game_scarlett_master.exe --execute
```
- It ran at about 30 fps and felt fast, all the way through the menus and loading.
- The intro video was not shown: no picture was displayed. Audio worked, including the voices of Lucia and Jason.
- When the game started rendering 3D, nothing was drawn. The last thing I saw was the coloured Rockstar Games text, and from then on the screen was black.
- No crash and no entry in `crashes.log` for this session. No driver reset or hang on my side.

The README lists the intro video as working, so the missing picture may be a difference on NVIDIA. The black world matches the "world" row of the status table. I have not tried the release build.

## 2. WARP (`VICTORY_D3D12_WARP=1`)
- It was extremely slow: about 10 fps (about 100 ms/frame, 16 draws/frame) in the menus, then down to about 1 fps (about 1300 ms/frame) with a black picture later on. In practice it was seconds per frame.
- At one point the host device was removed. `crashes.log`:

```

(0x887A0005); a diagnostics build with VICTORY_D3D12_DEBUG=1 names the command
```
(English: 0x887A0004 = DXGI_ERROR_UNSUPPORTED, 0x887A0005 = DXGI_ERROR_DEVICE_REMOVED.)

- I haven't captured logs with `VICTORY_D3D12_DEBUG=1` / `VICTORY_D3D12_DRED=1` yet. I can if useful.
