### Summary
Fixes 2 real bugs in `crates/victory-gpu/src/fence.rs` and `crates/victory-gpu/src/sampler.rs` and adds 11 deterministic synthetic unit tests.

Because external PR creation is currently restricted (`collaborators_only`), the CI-green branch is ready on my fork for cherry-pick / review:
- **Branch**: `geiyiliyabumo/VIctory@test/gpu-fence-and-sampler`
- **Commit**: `geiyiliyabumo/VIctory@370c61b` (based on `main` `ffe310e`)

### Changes
- **`crates/victory-gpu/src/fence.rs`**:
  - Fixed `signal` using `store` (which allowed a lower signal value to move a D3D12 fence backwards) to use `fetch_max(value, Ordering::AcqRel)`.
  - Added 5 unit tests (`fence::` **6/6 PASS**): monotonic signaling, creation flags & GPU address, COM interfaces/refcount, all 5 vtable slots, and Windows event waiters.
- **`crates/victory-gpu/src/sampler.rs`**:
  - Clamped decoded `D3D12_COMPARISON_FUNC` (`1..=8`) and `D3D12_TEXTURE_ADDRESS_MODE` (`1..=5`) enum words so out-of-range title descriptors do not cause host `CreateSampler` to silently drop the descriptor.
  - Added 6 unit tests (`sampler::` **7/7 PASS**): filter bits, comparison/reduction encoding, comparison & anisotropy clamping, LOD/bias/border, and address modes.

### Comment 1 — @andrewpozdnakov7-jpg — 2026-11-24T14:25:48Z

Native D3D12 permits fence values to decrease. With WARP on Windows 10, signals `5 → 2` left `GetCompletedValue()` at 2. A new event for 4 stayed pending until the next signal of 4. [D3D12 fence semantics](https://learn.microsoft.com/en-us/windows/win32/direct3d12/user-mode-heap-synchronization)

The VIctory regression test failed on `370c61b`: the same signals left the value at 5. The follow-up restores the latest signal value and checks that an event registered after a rewind waits for the next qualifying signal. [Fix and regression test](https://github.com/andrewpozdnakov7-jpg/VIctory/commit/3780ed782057f5894d7f6fb6cb956ea7cc87c02a)

The commit is directly on `370c61b`. After the fix, all 6 fence tests and 64 GPU diagnostics tests passed, with 1 existing benchmark ignored. Clippy and the asset policy check passed. AI-assisted.
