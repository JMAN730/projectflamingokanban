## Original body

`cargo test --workspace` doesn't build on `main` (58fed37):

```
error[E0061]: this function takes 2 arguments but 1 argument was supplied
    --> crates\victory-shader\src\emit\lower.rs:6963:13
```

25b0f88 added an `rsrc2` argument to the `lowers` test helper, and the bit-test loop at line 6963 still calls it with one. Passing `0` there, same as line 6851, fixes it and all the tests pass:

```diff
-            lowers(&words).unwrap();
+            lowers(&words, 0).unwrap();
```

I wanted to send this as a PR but GitHub won't let my account open one here. The commit is on `fix/lowers-test-missing-arg` in https://github.com/PikPakPik/VIctory if you want to pull it.
