### Summary
Fixes 3 real bugs in `crates/victory-gpu/src/shader_cache.rs` and expands deterministic synthetic unit tests from 2 to **12 passing tests**.

Because external PR creation is currently restricted (`collaborators_only`), the CI-green branch is ready on my fork for cherry-pick / review:
- **Branch**: `geiyiliyabumo/VIctory@test/gpu-shader-cache`
- **Commit**: `geiyiliyabumo/VIctory@f4c4bd4` (based on `main` `ffe310e`)

### Bugs Fixed (`crates/victory-gpu/src/shader_cache.rs`)
1. `RootType::Other(x)` was encoded as `6 + x`, causing `Other(u32::MAX)` to panic in debug and wrap into a named tag in release. Now encoded as tag word `OTHER_ROOT = 6` followed by the raw `u32` value (lossless, unknown tags rejected).
2. An unwritable/full-disk cache previously failed `get_or_convert` even after translation succeeded. Cache publication is now best-effort, reusing the translated result via `OnceLock` without translating twice.
3. `convert` sliced `&input[32..]` unconditionally (panicking on short input); now uses `split_at_checked(BUILD_LEN)` and returns an error.
