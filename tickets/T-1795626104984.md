## Summary

VIctory `main` at `ffe310e` boots the title, presents the first frames, and then stops with `0xc0000005` (read at `0x68`) at `victory-image-b99f876b74d4a77f.dll+0xb5a5f8`, immediately after `XUserAddAsync` and opening `core_licenses_data.rpf`. The same address occurs in both the release build and a diag build with WARP.

The game files are complete for this run: `TitleID=7952987A`, all four title DLLs are loaded (`XboxBvhBuilder.dll`, `amd_fidelityfx_loader_xbox.dll`, `libHttpClient.GDK.dll`, `Bink2Scarlett.dll`), and `imports bound ... 72 title, 0 missing`. A manifest/path problem is therefore not involved.

## Environment

- OS: Windows 10 Pro 22H2, build `19045.7807`
- GPU: NVIDIA GeForce RTX 3060 Laptop GPU, driver `32.0.16.1062`
- VIctory: `main` `ffe310e`, release and diag builds
- Game build: `unknown (b99f876b74d4a77f03af5f878223b27bd647b5c35a79d5decd9f716504239e93)`, Series X 1.0.2.1
- Launcher wrapper: VIctoryKit (runs `victory.exe run <exe> --execute --console series-x`; WARP uses `VICTORY_D3D12_WARP=1`)
- Data/cache: separate folders outside the game directory

## Steps

1. Run `victory.exe run <game_dir>\game_scarlett_master.exe --execute --console series-x`
2. Let the title initialize until the first presented frames
3. It stops with the exception below, before any user interaction

Same result with `victory-diag.exe` and `VICTORY_D3D12_WARP=1`; WARP does not change the crash address.

### Comment 1 — @EduBertozzi — 2026-11-24T14:48:43Z

This looks like #741, which has the same address (`+0xb5a5f8`, read at `0x68`) on Windows 10 with `main`. There, and in #348, the cause was the in-box D3D12 runtime on Windows 10. It stops at shader model 6.5 and refuses the root signatures every translated pipeline uses. Your log should show `root signature: Unsupported bit-flag set` / `host root signature refused` warnings before the crash. WARP doesn't help, because it goes through the same in-box runtime.

On #741, testing #175 with the D3D12 Agility runtime beside `victory.exe` (`cargo xtask agility`) got past Game Init into the menus. #969 does the same without exe exports: set `VICTORY_D3D12_AGILITY` to a folder holding the 1.620 `D3D12Core.dll`. I confirmed it reaches SM 6.6 on Windows 10 19045 in the test suites. If either gets you past this point, that confirms the duplicate.
