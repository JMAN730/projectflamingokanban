## Original body

`ID3D12GraphicsCommandList::DiscardResource` (vtable slot `55`, `0x1b8`) currently falls into `missing_table` on both older and newer command-list layouts.

### Tested Fix Ready on Fork
External PR creation is currently restricted (`collaborators_only`), so the verified patch is ready on my fork (based on `main` `ffe310e`):
- Branch: https://github.com/geiyiliyabumo/VIctory/tree/feat/list-discard-resource
- Commit: https://github.com/geiyiliyabumo/VIctory/commit/735f3af

**Changes (`crates/victory-gpu/src/list.rs`, `crates/victory-gpu/src/host.rs`):**
- Wires `discard_resource` at slot `55` (`0x1b8`) on both `LIST_FUNCTIONS` and `NEWER_LIST_FUNCTIONS`, with compile-time Windows ABI size/alignment assertions against `D3D12_DISCARD_REGION` and `RECT`.
- Adds read-only `HostList::tracked_texture_state` and only forwards `DiscardResource` when the current list holds the host texture in a discard-legal state (`RENDER_TARGET`, `DEPTH_WRITE`, or `UNORDERED_ACCESS`) matching the texture's resource flags; null/buffer resources, invalid regions, and untracked/incompatible textures are clean no-ops without introducing spurious barriers.
- Validates `DiscardRegion` bounds (subresource range with `D3D12_FEATURE_FORMAT_INFO` plane count, overflow safety, 2D-only and single-mip-extent rules for rects, non-inverted rect geometry).
- Adds 4 synthetic unit + live D3D12 tests (`discard_resource_slot_is_stable`, `discard_region_validation`, `discard_requires_matching_state_and_flags`, `discard_resource_executes_on_guest_queue`).

**Verification (Windows 11 Pro 26100, AMD Radeon RX 9060 XT driver `32.0.32029.2010`, Rust `1.98.1`):**
- `cargo xtask policy`: PASS (`154 files ok`)
- `cargo clippy --workspace --all-targets --locked -- -D warnings`: PASS
- `cargo clippy --workspace --all-targets --features diagnostics --locked -- -D warnings`: PASS
- `cargo test -p victory-gpu --locked -- discard --nocapture`: **4/4 PASS** (`live discard adapter: AMD Radeon RX 9060 XT`)
- `VICTORY_D3D12_WARP=1 cargo test -p victory-gpu --features diagnostics --locked -- discard --nocapture`: **4/4 PASS** (`live discard adapter: Microsoft Basic Render Driver`)
