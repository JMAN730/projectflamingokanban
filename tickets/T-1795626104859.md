## Original body

`bfe_signed_and_unsigned_match_rdna2` in `valu_tests.rs` builds shaders for `v_bfe_i32` (VOP3 0x149), `v_bfe_u32` (VOP3 0x148) and `s_bfe_i32` (SOP2 0x28). The scalar unsigned variant `s_bfe_u32` (SOP2 0x27) is never tested, even though it is handled in the same `match` arm.

## Implementation evidence

`lower.rs`, `sop()` at line 2638:

```rust
"s_bfe_u32" | "s_bfe_i32" => {
    // src1: offset in bits 0-4, width in bits 16-22.
    let (a, b) = (src32(self, 0)?, src32(self, 1)?);
    let (k16, k127) = (self.s.m.i32(16), self.s.m.i32(0x7F));
    let w = self.s.m.bin(c, Bin::LShr, b, k16);
    let w = self.s.m.bin(c, Bin::And, w, k127);
    (self.bfe(a, b, w, name == "s_bfe_i32"), None)
}
```

`s_bfe_u32` passes `signed=false` to `bfe()`. The 7-bit width field (`src1[22:16]`) is unique to SOP2: a width of 32..127 means "return all bits from the shifted source", exercising the `full = width >= 32` branch of `bfe()`.

## Missing test

`valu_tests.rs`, `bfe_signed_and_unsigned_match_rdna2` (line 794), builds:

| Variable | Instruction | Opcode | Present |
|---|---|---|---|
| `v_signed` | `v_bfe_i32` | VOP3 0x149 | ✅ |
| `v_unsigned` | `v_bfe_u32` | VOP3 0x148 | ✅ |
| `s_signed` | `s_bfe_i32` | SOP2 0x28 | ✅ |
| _(absent)_ | `s_bfe_u32` | SOP2 **0x27** | ❌ |

The signed scalar path exercises `bfe(…, true)` with the 7-bit width and the `width >= 32` branch (`[0x8000_0000, 4, 32, 0] → 0xf800_0000`). The unsigned scalar equivalent (`bfe(…, false)` with the same 7-bit encoding, no sign extension) is not tested. The expected result for width=32 differs: `0x0800_0000` unsigned vs `0xf800_0000` signed.

## Suggested test addition

Add a fourth shader `s_unsigned` to `bfe_signed_and_unsigned_match_rdna2`:

```rust
// s_bfe_u32 s6, s0, s1 (SOP2 opcode 0x27)
let s_unsigned = build_valu_cs(&[sop2(0x27, 6, 0, 1), vop1(0x001, 0, sgpr(6))]);
```

Then run the same `s_in` cases against it, plus the width=32 edge case:

```rust
let mut su_cases = unsigned_cases.to_vec();
// width=32: s_bfe_u32 7-bit width keeps all bits; no sign extension.
su_cases.push(([0x8000_0000, 4, 32, 0], 0x0800_0000));
let su_in: Vec<[u32; 4]> = su_cases
    .iter()
    .map(|&(inp, _)| [inp[0], (inp[1] & 31) | ((inp[2] & 0x7F) << 16), 0, 0])
    .collect();
run_cases(&s_unsigned, &su_in, |backend, i, inp, got| {
    let want = su_cases[i].1;
    assert_eq!(
        got, want,
        "{backend}: s_bfe_u32({:#010x}, {:#010x}) = {got:#010x}, want {want:#010x}",
        inp[0], inp[1],
    );
});
```

The key case that differs from the signed test: `([0x8000_0000, 4, 32, 0], 0x0800_0000)` — width=32 on a 7-bit field extracts all bits from offset 4 without sign-extending bit 31.

No game data needed; the test skips when no SM 6.6 device is available and runs on WARP.

**AI-assisted:** found with Kiro (Claude) and independently confirmed by five separate analysis passes without cross-contamination; no hardware run, no game data.
