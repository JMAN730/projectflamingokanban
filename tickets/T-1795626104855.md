## Original body

`v_cmp_class_f32` (VOPC opcode 0x088) is fully implemented in `crates/victory-shader/src/emit/lower.rs` but has no synthetic hardware test in `crates/victory-shader/src/emit/valu_tests.rs`. Its sibling `v_cmp_class_f16` (VOPC 0x08f) has an exhaustive test added in #140.

## Implementation evidence

`lower.rs`, `compare()` at line 5097, handles both types in one branch:

```rust
"f32" | "f16" if op == "class" => {
    let f16 = ty == "f16";
    let x = if f16 {
        // half_src() extracts 16-bit operand
    } else {
        let x = self.fsrc(inst, 0)?;   // f32-specific path
        self.as_int(x)
    };
    let (exp_sh, sign_sh, exp_mask, mant_mask, quiet_bit) = if f16 {
        (10, 15, 0x1F, 0x03FF, 0x0200)
    } else {
        (23, 31, 0xFF, 0x7F_FFFF, 0x40_0000)   // f32 constants, never tested
    };
```

The f32 path uses distinct constants (`exp_sh=23`, `mant_mask=0x7F_FFFF`, `quiet_bit=0x40_0000`) that differ from f16 and are only reachable when `ty == "f32"`.

## Missing test

`valu_tests.rs` contains `fn v_cmp_class_f16_matches_rdna2()` (line 868) which covers all 10 IEEE-754 binary16 classes using `vop3(0x08f, ...)`. Opcode `0x088` (`v_cmp_class_f32`) does not appear anywhere in the test file.

## Suggested test

Add `fn v_cmp_class_f32_matches_rdna2()` to `valu_tests.rs` mirroring the f16 test:

```rust
#[test]
fn v_cmp_class_f32_matches_rdna2() {
    // v_cmp_class_f32_e64 s6, v1, v2 (VOP3 encoding of VOPC 0x088)
    // v_cndmask_b32_e64 v0, 0, 1, s6
    let cmp = build_valu_cs(&[
        vop3(0x088, 6, vgpr(1), vgpr(2), 0)[0],
        vop3(0x088, 6, vgpr(1), vgpr(2), 0)[1],
        vop3(0x101, 0, 0x80, 0x81, sgpr(6))[0],
        vop3(0x101, 0, 0x80, 0x81, sgpr(6))[1],
    ]);

    // All 10 IEEE-754 binary32 classes: bit k corresponds to class k.
    // quiet_bit = 0x40_0000 (bit 22).
    let classes: &[(u32, u32)] = &[
        (0x7F80_0001, 0), // +sNaN  (quiet bit clear, mantissa != 0)
        (0xFF80_0001, 0), // -sNaN
        (0x7FC0_0000, 1), // +qNaN  (quiet bit set)
        (0xFFC0_0001, 1), // -qNaN
        (0xFF80_0000, 2), // -inf
        (0xBF80_0000, 3), // -normal (-1.0)
        (0x8000_0001, 4), // -denormal
        (0x8000_0000, 5), // -0.0
        (0x0000_0000, 6), // +0.0
        (0x0000_0001, 7), // +denormal
        (0x3F80_0000, 8), // +normal (+1.0)
        (0x7F80_0000, 9), // +inf
    ];
    let mut cases = Vec::new();
    for &(bits, cls) in classes {
        cases.push(([bits, 1u32 << cls, 0, 0], 1u32));
        cases.push(([bits, 0x3FF & !(1u32 << cls), 0, 0], 0u32));
    }
    let inputs: Vec<[u32; 4]> = cases.iter().map(|c| c.0).collect();
    run_cases(&cmp, &inputs, |backend, i, inp, got| {
        let want = cases[i].1;
        assert_eq!(got, want, "{backend}: v_cmp_class_f32({bits:#010x}, {cls:#05x}) = {got}, want {want}");
    });
}
```

The test skips gracefully when no SM 6.6 device is available and runs on WARP. No game data needed.
