## Work

The title writes packed light into an integer texture from compute, then samples the same memory through a view of another format placed at the same address (sky, probes, bounced light). On the host these are two textures. The sampled one is filled from title memory that nobody wrote, so it reads black. When a view is placed over memory a host-written texture already covers, fill it from that host texture.

## Done when

A synthetic test writes a texture from compute, samples it through a second view of a different format with the same texel width at the same address, and reads the written values on a hardware device and on WARP.

## Context

Surfaced by the research on a lit public tree, which ranks this third among the differences that could explain a dark lighting result. The host only copies between formats of equal texel width by going through a buffer. Write our own implementation: that tree's loader carries code from a project under a licence that does not match ours, so nothing is taken from it without checking.
