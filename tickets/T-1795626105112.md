## Original body

`cargo test -p victory-shader` does not build, so not one test in that
crate runs:

```
error[E0061]: this function takes 2 arguments but 1 argument was supplied
   --> crates/victory-shader/src/emit/lower.rs:6954:13
```

`lowers` gained its second parameter (the RSRC2 dispatch resource register) in
3c86053, and the scalar-bit test kept the old one-argument call. Not platform
specific: the test target fails on every host, and it only shows up once the
tests are built.

The four programs in `scalar_bit_tests_lower` ask for nothing beyond the group
ID, so 0 is the right value, same as the add/sub pair just above.

```diff
--- a/crates/victory-shader/src/emit/lower.rs
+++ b/crates/victory-shader/src/emit/lower.rs
@@ -6960,7 +6960,9 @@ mod tests {
         ];
         for head in bit_tests {
             let words: Vec<u32> = head.iter().chain(&tail).copied().collect();
-            lowers(&words).unwrap();
+            // These programs ask for nothing beyond the group ID: rsrc2 stays 0,
+            // like the add/sub pair above.
+            lowers(&words, 0).unwrap();
         }
     }
 
```

With that, `cargo test -p victory-shader` gives 70 passed, 0 failed.

I cannot open a pull request because this repository limits pull requests to
collaborators, so here it is as an issue. Happy to send it as a PR if that
opens up, and there is a second build failure on Linux behind this one (an
ungated `#[cfg(windows)]` helper in `victory-gpu/src/resource.rs`) that I can
report the same way.
