## Original body

Title: Test only_loopback_is_reachable fails on Windows 10: host winhttp.dll lacks WinHttpGetProxySettingsEx

On Windows 10 22H2 (10.0.19045.6456 x64), cargo test --workspace gives 85 passed / 1 failed. Panic at crates/victory-hle/src/modules/net.rs:1058: winhttp.dll lacks WinHttpGetProxySettingsEx. The assert checks every override names a real export of its host DLL via GetProcAddress on System32 winhttp.dll, but this export doesn't exist in Windows 10's winhttp.dll (verified against the 10.0.19041 export table — WinHttpGetProxyResultEx and WinHttpGetProxyForUrlEx are present, WinHttpGetProxySettingsEx is not). Since README states Windows 10/11 are supported, either the test or the README needs updating.
