## Original body

On an RTX 5070 Ti (driver 621.14, Windows, Series X mode), the ped skinning compute shader selected a bindless raw vertex buffer from a CBV at byte offset 0x40. In a local diagnostics build, its selected host slot was null even though the title buffer contained nonzero vertex data. This provides a live case for #413 and the scalar heap-buffer translation discussed in #1015.

How to check this on another build

1. In CS_PedStandardSkinning_7 (fb332f777bae57fb), record the index consumed at 0x6c, the heap byte offset at 0x70, and the two dwords read by the lane at 0x3204. Match by dispatch, lane, and view-relative byte offset. The descriptor index varies across runs.
2. Compare the slot state and title bytes at bind time. In the baseline, all 96 paired samples had a null host slot and returned two zeros from nonzero source bytes. With the dynamically selected raw SRV materialized and refreshed, and scalar header reads at 0x8c/0x94 translated through a raw SRV, all 112 paired samples in a later run agreed word for word. This covered 16 distinct offsets.
3. Follow the other writers as well. In a 32 KiB sampling window, 3,072 mesh lane reads matched the near-zero position encoding seen at the same byte offsets after earlier fenced skinning submissions. The last observed change came from variants _4 and _8, 1,536 lane observations each. Fixing _7 alone left the sampled triangles collapsed.

After extending the local handling to _4 and _8, one run of the instrumented stack recorded 14,521 sampled triangles with nonzero projected area for mesh ef5409053e14aa82 / pixel 94d281151ca58b4f. Pipeline statistics for the tracked indirect mesh draws recorded 634,040 pixel shader invocations across two fences. All 122 sampled groups had allocations matching the vertex and primitive counts in the meshlet record. Another run reached only empty draws. The process still eventually reported device removal.

These are GPU measurements. Final composite visibility was not checked. The local stack also includes mesh and culling translation changes and aligned structured SRV handling related to #984 and #986. Scene scheduling varied, and the host materialization and scalar lowering changes were tested together. An independent check of the source-word comparison on a current integration would help establish which changes are needed upstream.

AI-assisted local instrumentation and analysis. No game files attached.
