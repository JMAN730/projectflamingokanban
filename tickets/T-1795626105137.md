### What you did

```text
**Summary**
Reproducible `DXGI_ERROR_DEVICE_HUNG` (`0x887A0006`) on Windows + AMD RX 6600 when running `game_scarlett_master.exe` (Title `7952987A`) through `victory.exe` with `VICTORY_COPY_MODE="none"`.

Crashes cluster into two deterministic patterns depending on `VICTORY_D3D12_DEBUG`:
1. **`VICTORY_D3D12_DEBUG=0`:** Device removal accompanied by a repeatable GPU page fault at `0x1f51d0000` or `0x1b31d0000` (consistent low 20 bits `...d0000`) and view/sampler heap past-end offsets (`0xed200000` / `0xed1ff800`).
2. **`VICTORY_D3D12_DEBUG=1` (with or without `VICTORY_WAVE64_EMULATE=1`):** Reports `0x887A0004` (`DXGI_ERROR_UNSUPPORTED`) + `0x887A0006` (`DXGI_ERROR_DEVICE_HUNG`) with **no breadcrumbs**, even on 4-list submissions with 0 slow host submissions, 0 untranslated shader warnings, and no Windows System TDR/driver reset events.

**Environment**
- **OS:** Windows
- **GPU:** AMD Radeon RX 6600 — Driver `32.0.21045.29003` (2026-11-16)
  - *(Other adapters present: AMD Radeon(TM) Graphics `32.0.21045.29003`, Meta Virtual Monitor `11.1.45.729`)*
- **Commit:** `70564ae` (clean working tree)
- **Binary:** `target\diag\victory.exe` (`b99f876b74d4a77f03af5f878223b27bd647b5c35a79d5decd9f716504239e93`)
- **Env flags tested:**
  - `VICTORY_COPY_MODE="none"`
  - `VICTORY_D3D12_DEBUG=0` vs `1`
  - `VICTORY_WAVE64_EMULATE=0` vs `1` (no change in crash behavior)

**Pre-Crash Log Observations**
- **Disallowed host UAV view:** Repeatedly logged before crash:
  `WARN victory_gpu::descriptor::host: view the host does not allow unordered=true format=53 flags=2` (`DXGI_FORMAT_R16_TYPELESS` UAV)
- **Unimplemented D3D12.X device methods:**
  - `slot=0x218` (`caller="+0x24800db"`)
  - `slot=0x1c8` (`caller="+0x247757e"`)
- **Pipeline library warnings:** `ID3D12PipelineLibrary::Load*Pipeline` desc mismatches (ID `972`) and duplicate `StorePipeline` (ID `970`) for `ed4d93c2274a7959abf164fb5108ab95`, `46b692d54e0feb58e4543ae70529c810`, `9faa1f75b56398592efc74728aed0aa5`.
- **Submission state:** 0 untranslated shader warnings, 0 slow host submissions, crash occurs on a 4-list submission.

**Suspected Causes**
1. **`VICTORY_COPY_MODE="none"` leaving descriptor/indirect data stale:** Skipping host copies may leave bindless descriptor tables or indirect argument buffers out of sync, producing the `0xed200000` / `0xed1ff800` past-end offsets and `...d0000` page faults.
2. **Dropped `R16_TYPELESS` UAV (`format=53`, `flags=2`):** Failing to create this host UAV may leave an invalid descriptor slot that faults immediately on first shader access.
3. **Instant fault vs. TDR:** The absence of Windows TDR events and DRED breadcrumbs under `VICTORY_D3D12_DEBUG=1` points to an immediate command-processor/page-fault rejection rather than a shader hang.
```
