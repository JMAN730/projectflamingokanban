## Original body

### Environment
- **OS:** Windows 10/11 x64 (AtlasOS)
- **GPU:** NVIDIA (D3D12 Mesh Shaders supported)
- **Title Build:** `7952987A` (Xbox Series X)
- **VIctory Build:** `diag` profile (`b99f876b74d4a77f03af5f878223b27bd647b5c35a79d5decd9f716504239e93`)

### Behavior Observed
When running the title on an NVIDIA GPU:
1. Audio works properly (APU & DSP connect and play) and the title progresses through boot/menus into `story000` at ~0.7–1.5 FPS without crashing or causing a TDR/driver reset.
2. However, the screen remains black (while the display triggers HDR even though VIctory logs `HDR mode: disabled (SDR presentation)`).

### Key NVIDIA / D3D12 Errors from Logs
1. **Descriptor Heap Limit (NVIDIA 1M Tier 1/2 CBV_SRV_UAV limit):**
   `WARN victory_gpu::descriptor::host: host view heap capped at 1000000 error=The parameter is incorrect. (0x80070057) count=1245184`
   This later triggers cascading warnings: `WARN victory_gpu::descriptor::host: no free dynamic descriptor slots: a table is not made` and thousands of dropped draws.

2. **Host Texture Creation Failures (`0x80070057`):**
   - `WARN victory_gpu::resource: no host texture error=The parameter is incorrect. (0x80070057) desc=ResourceDesc { dimension: 3, alignment: 0, width: 2560, height: 1440, depth_or_array_size: 1, mip_levels: 1, format: 86, sample_count: 1, sample_quality: 0, layout: 0, flags: 5 }`
   - `WARN victory_gpu::resource: no host texture error=The parameter is incorrect. (0x80070057) desc=ResourceDesc { dimension: 3, alignment: 0, width: 2560, height: 1440, depth_or_array_size: 1, mip_levels: 1, format: 115, sample_count: 1, sample_quality: 0, layout: 0, flags: 1 }`
   - `WARN victory_gpu::descriptor::host: view the host does not allow unordered=true format=53 flags=2`

3. **Compute Pipelines Refused by NVIDIA Driver (`0x80070057`):**
   Several translated compute shaders are refused at PSO creation time on NVIDIA, e.g.:
   `WARN victory_gpu::pipeline::host: host pipeline refused error=The parameter is incorrect. (0x80070057) shaders=[compute 13dfdd3b1136e407]` (also seen for `88994c3496045f51`, `02384a60fda6f2d0`, `339d476c267c03c7`, `2fa2f94f560faf39`, `a25ed0e3d4d521ba`, `fa0c0819dc86ca60`, `9e096a1111c6faaa`, `00bcbbf278ee3d9d`, `0709e8356abd9082`, `e4576c6eca0f8ce3`).

*(Happy to test any branches or provide additional logs with the D3D12 debug layer enabled if needed!)*
