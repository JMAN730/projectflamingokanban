## 结论

能编译、能启动、菜单阶段完整可交互并稳定 30 fps；**在"选中 PLAYER 之后的过场/主菜单加载"处，宿主 D3D12 设备被移除（TDR），进程退出**。
这与仓库 README 自己写的状态完全一致，但在 RDNA4 上是首次验证。

> **警告（实测）**：真 GPU 重跑时，这台机器在 19:57:49 **整机冻结**并自行重启（Kernel-Power 41，无蓝屏转储），
> 不是普通 TDR。在缺陷修好之前不要用真 GPU 跑，见第 6 节。WARP（软件适配器）只掉进程、不挂系统。

## 4. 失败细节

`%LOCALAPPDATA%\victory\data\7952987A\crashes.log`（两次都在同一处）：

```
VIctory: host GPU failure: host GPU device removed after a submission of 32 lists; no breadcrumbs
(DXGI_ERROR_UNSUPPORTED 0x887A0004); device removed: GPU 不响应更多命令 (0x887A0006)
```

崩溃前的日志顺序（两次一致）：

1. 多个 pixel/compute shader 翻译失败，draw 被丢弃：
   - `a 64-bit image atomic is not supported`
   - `a lane-mask join of an untracked ...`
   - `an address not from a root parameter`
   - `an LDS write of bytes or halves ...`
2. `WARN victory_gpu::descriptor::host: no free dynamic descriptor slots: a table is not made`
3. `ERROR victory_gpu::host: host GPU device removed after a submission of 32 lists`
4. 进程退出码 `0x887A0005`（DXGI_ERROR_DEVICE_REMOVED 直接作为进程退出码）

推断：主菜单加载阶段的计算着色器（大量未翻译 → 丢弃）+ 动态描述符表耗尽，
综合导致一次非法提交，驱动直接 TDR。0x887A0004 说明还有某个"本系统不支持"的能力被请求。


### 4b. 软件适配器（WARP）同样崩

同一路径用 `VICTORY_D3D12_WARP=1` 再跑一遍（15 fps 菜单 → 7.5 fps 过场）：

```
WARN victory_gpu::pipeline::host: host mesh pipeline refused error=GPU 设备实例已经暂停
ERROR victory_gpu::host: host GPU device removed after a submission of 1 lists
```

`crashes.log` 记录 `0x887A0004`（DXGI_ERROR_UNSUPPORTED）+ `0x887A0005`（DEVICE_REMOVED）。

**这是本次最重要的发现**：软件适配器也不死，硬件也死，说明问题不在 RDNA4 驱动，
而在 VIctory 自己提交的某条命令/描述符（紧邻的 `no free dynamic descriptor slots: a table is not made` 警告高度可疑），
以及 WARP 下 mesh pipeline 创建被拒。也就是说这个坎是可修的 bug，不是"这张卡不行"。

## 5. 可以继续试的方向

| 手段 | 目的 |
|---|---|
| `VICTORY_D3D12_WARP=1` | 软件适配器，绕开驱动；可验证是"逻辑"还是"驱动/RDNA4"问题（很慢） |
| `VICTORY_D3D12_DEBUG=1` + `VICTORY_D3D12_GBV=1` | 需要装 D3D12 验证层，能指出具体非法命令 |
| `VICTORY_D3D12_DRED=1` | 失败时给出命中的分配和飞行中的命令 |
| `VICTORY_SKIP_PIPELINES=<hash>` | 按崩溃前日志里的 16 位 shader 哈希逐个屏蔽，二分定位 |
| `VICTORY_GPU_TIMING=1` | 找出超时的命令列表 |
| 减小窗口/分辨率 | 降低 TDR 概率，先确认主菜单能否显示 |


## 6. 19:57 整机硬冻结（重要）

用启动脚本在 **真 GPU** 上重跑一次，机器在 19:57:49 直接卡死，19:59:04 自行重启。

| 证据 | 内容 |
|---|---|
| System 日志 Event 41 (Kernel-Power) | 未正常关机就重启 |
| System 日志 Event 6008 | 上一次关闭（19:57:49）是意外的 |
| BugCheck 1001 | **没有** —— 不是蓝屏，是硬冻结，连转储都没来得及写 |
| crashes.log | 最后一次运行：`device removed after a submission of 28 lists` + `0x887A0004` / `0x887A0006` |

也就是说 README 警告的"进世界会挂显卡"在这台机器上是**整机挂死**，不是掉一次驱动。
在 VIctory 修掉那次非法提交（动态描述符槽耗尽 / 无效命令）之前，**不要再用真 GPU 跑**。

## 7. 启动脚本

`E:\GTA\GTA6.Xbox\victory-start.ps1`（默认 WARP 安全模式，真 GPU 需显式 -RealGPU）

```powershell
.\victory-start.ps1                    # 软件适配器，菜单阶段，安全
.\victory-start.ps1 -List              # 只打印将要执行什么
.\victory-start.ps1 -Diag -Auto        # diag 构建 + 自动按 A 推菜单
.\victory-start.ps1 -RealGPU -Yes      # 真 GPU，会挂机器
```
