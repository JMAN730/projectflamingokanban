## Original body

On `ffe310e`, creating a texture with `MipLevels = 0` allocates the full mip chain, but the guest resource's `GetDesc` returns zero. Native D3D12 returns the allocated count. A clear loop driven by that descriptor skips every mip of a synthetic 4×4 texture.

| Synthetic check | Stock | Patched |
| --- | ---: | ---: |
| 4×4 automatic chain, matching texels across all three mips | 0/21 | 21/21 |
| Explicit two-mip control, matching texels | 20/20 | 20/20 |
| Ordinary buffer, reported mip count | 1 | 1 |

RTX 5090 and WARP gave the same results. Automatic 1D, 2D, 2D array, and 3D cases also reported the same counts as native D3D12 after the patch. Both diagnostic runs passed 53 tests with one benchmark ignored.

[Source commit](https://github.com/fuzeofficlal/VIctory/commit/ec64d8d5959df14243437d207c725d235ab1c9f0) uses the existing mip-count calculation when returning the descriptor for an automatically sized texture.
