- fcdf58: gpu: add indirect draw stream compaction pass to eliminate empty draw stalls
- ^G936a6a: shader: clamp WaveSize to hardware capability and ensure bit-exact NaN handling

### Summary

1. **Indirect draw stream compaction**:
Empty indirect draw calls from engine passes caused 0.5 to 1.8 second stalls on hardware command queues. We add an atomic compute shader compaction pass and HostList CompactionScratch UMA arena in crates/victory-gpu to filter zero-instance records before ExecuteIndirect dispatch.

2. **WaveSize hardware clamping and bit-exact NaN detection**:
Intel Arc DG2 hardware executes waves of width 32 rather than 64. We add wave_size_max() clamping via VICTORY_WAVE_SIZE_MAX in crates/victory-shader/src/emit/mod.rs and lower.rs so compute threadgroups respect the 32-lane hardware limit. We also implement bit-exact NaN detection in vector median3 operations.

### Verification
- Tested on Intel Arc A770 (16GB, Driver 32.0.101.9175) under Windows 11.
- cargo test --workspace: 142 passed, 0 failed, 4 ignored.
