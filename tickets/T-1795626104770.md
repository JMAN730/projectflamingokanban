**Description:**
The emulator crashes with an unhandled exception (0xc0000005) when trying to load into the game world. This happens consistently on both the standard GPU build and the WARP software renderer.

**Error Sequence:**
Prior to the crash, the console logs show the host rejecting root signatures:
- `root signature: Unsupported bit-flag set (root signature flags c01)`
- `host root signature refused error=The parameter is incorrect. (0x80070057)`
- `dropped 3 without a host pipeline`

**Crash Details:**
- Build Hash: `b99f876b74d4a77f03af5f878223b27bd647b5c35a79d5decd9f716504239e93`
- Faulting Module: `victory-image-b99f876b74d4a77f.dll+0xb5a5f8`
- Exception: `0xc0000005 (read 0x68)` - Indicates a null pointer dereference, likely because the pipeline failed to create.
