## Original body

Six integer three-way operations are implemented in `crates/victory-shader/src/emit/lower.rs` but have no synthetic hardware tests in `crates/victory-shader/src/emit/valu_tests.rs`. Their float siblings (`v_med3_f32`, `v_min3_f32`, `v_max3_f32`) are tested; the integer variants are not.

## Affected instructions

| Instruction | VOP3 opcode | Tested sibling |
|---|---|---|
| `v_min3_i32` | 0x152 | `v_min3_f32` (0x151) ✓ |
| `v_min3_u32` | 0x153 | `v_min3_f32` (0x151) ✓ |
| `v_max3_i32` | 0x155 | `v_max3_f32` (0x154) ✓ |
| `v_max3_u32` | 0x156 | `v_max3_f32` (0x154) ✓ |
| `v_med3_i32` | 0x158 | `v_med3_f32` (0x157) ✓ |
| `v_med3_u32` | 0x159 | `v_med3_f32` (0x157) ✓ |

## Implementation evidence

`lower.rs`, `valu_op()` around line 4889:

```rust
"v_min3_i32" | "v_max3_i32" | "v_min3_u32" | "v_max3_u32" | "v_med3_i32"
| "v_med3_u32" => {
    let (a, b, d) = (s(self, 0)?, s(self, 1)?, s(self, 2)?);
    let signed = name.ends_with("i32");
    let (lt, gt) = if signed {
        (pred::SLT, pred::SGT)
    } else {
        (pred::IULT, pred::IUGT)
    };
    let pick = |l: &mut Self, p, x, y| {
        let t = l.s.m.cmp(c, p, x, y);
        l.s.m.select(c, t, x, y)
    };
    match &name[2..6] {
        "min3" => { let t = pick(self, lt, a, b); pick(self, lt, t, d) }
        "max3" => { let t = pick(self, gt, a, b); pick(self, gt, t, d) }
        _ => {  // med3
            let lo = pick(self, lt, a, b);
            let hi = pick(self, gt, a, b);
            let t  = pick(self, lt, hi, d);
            pick(self, gt, lo, t)
        }
    }
}
```

The signed/unsigned predicate switch (`SLT`/`SGT` vs `IULT`/`IUGT`) is the only difference from the float path and is exercised by no test.

## Missing test

`valu_tests.rs` contains `fn v_med3_f32_matches_rdna2_with_nan()` (line 262) and `fn v_med3_f16_matches_rdna2_with_nan()` (line 335) for the float variants. No function in the file references opcodes `0x152`–`0x159`.

## Suggested test

Add `fn v_med3_min3_max3_integer_matches_rdna2()` to `valu_tests.rs`:

```rust
#[test]
fn v_med3_min3_max3_integer_matches_rdna2() {
    // Build one shader per instruction.
    let make = |op: u32| build_valu_cs(&vop3(op, 0, vgpr(1), vgpr(2), vgpr(3)));

    let min3_i = make(0x152); // v_min3_i32
    let min3_u = make(0x153); // v_min3_u32
    let max3_i = make(0x155); // v_max3_i32
    let max3_u = make(0x156); // v_max3_u32
    let med3_i = make(0x158); // v_med3_i32
    let med3_u = make(0x159); // v_med3_u32

    // (a, b, c, min_i32, max_i32, med_i32, min_u32, max_u32, med_u32)
    let cases: &[([u32; 4], u32, u32, u32, u32, u32, u32)] = &[
        // Plain ascending order
        ([1, 2, 3, 0], 1, 3, 2, 1, 3, 2),
        // Reversed
        ([3, 2, 1, 0], 1, 3, 2, 1, 3, 2),
        // All equal
        ([7, 7, 7, 0], 7, 7, 7, 7, 7, 7),
        // Two equal (low)
        ([1, 1, 5, 0], 1, 5, 1, 1, 5, 1),
        // Two equal (high)
        ([5, 9, 9, 0], 5, 9, 9, 5, 9, 9),
        // Signed: negative values
        ([((-3i32) as u32), ((-1i32) as u32), 2, 0],
            (-3i32) as u32, 2, (-1i32) as u32,
            2, ((-1i32) as u32), ((-3i32) as u32)), // unsigned: -3=0xFFFFFFFD is largest
        // Signed extremes
        ([0x8000_0000, 0x7FFF_FFFF, 0, 0],
            0x8000_0000, 0x7FFF_FFFF, 0,
            0, 0x8000_0000 /*UINT_MAX-1*/ , 0x7FFF_FFFF),
    ];

    let inputs: Vec<[u32; 4]> = cases.iter().map(|c| c.0).collect();

    let check = |name: &str, shader: &_, expected: fn(&([u32;4], u32, u32, u32, u32, u32, u32)) -> u32| {
        run_cases(shader, &inputs, |backend, i, inp, got| {
            let want = expected(&cases[i]);
            assert_eq!(got, want, "{backend}: {name}({:#010x}, {:#010x}, {:#010x}) = {got:#010x}, want {want:#010x}", inp[0], inp[1], inp[2]);
        });
    };

    check("v_min3_i32", &min3_i, |c| c.1);
    check("v_max3_i32", &max3_i, |c| c.2);
    check("v_med3_i32", &med3_i, |c| c.3);
    check("v_min3_u32", &min3_u, |c| c.4);
    check("v_max3_u32", &max3_u, |c| c.5);
    check("v_med3_u32", &med3_u, |c| c.6);
}
```

No game data needed; the test skips when no SM 6.6 device is available and runs on WARP.

**AI-assisted:** found with Kiro (Claude) and independently confirmed by five separate analysis passes without cross-contamination; no hardware run, no game data.
