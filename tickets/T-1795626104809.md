## Original body

**Setup:** Windows 11 Pro 26300, Ryzen 7 5800X3D, 32 GB, AMD RX 9070 XT (driver 32.0.32029.2010),
retail title 1.0.2.1, build `c7a5f49` (release) and the same commit as a `diag` build.
`game_dir` points at my own dump; `victory.toml` otherwise default.
**What works:** boot screens, intro video with sound, start screen, profile, loading into the
world (~50 s), the first mission's intro and its title card. The window caption shows ~1 fps in the
world; menus were 30 fps for me. GPU sits at ~38%, so this is not GPU-bound.
**Translate pass** (`victory translate --pipelines`, ran to completion on this dump):
```
programs     26148 translated of 26148 (40647088 IR instructions)
DXIL         12236 emitted of 14013 vertex and pixel programs
             1440 emitted of 2581 compute programs
             8163 emitted of 8506 mesh programs
      653  emit: a 64-bit image atomic
      604  emit: a scalar memory read as data
      388  emit: a descriptor read only as data
      298  resources: a descriptor neither loaded nor built
      288  emit: a select on an untracked mask
```
**Run** (`VICTORY_GPU_TIMING=1`, diag build, no capture): the title reaches the world and renders
the title card, then the scene is dark. The log (debug level) shows the scene is being dropped
rather than drawn:
```
WARN victory_gpu::pipeline: shader does not translate; its pipelines' draws are dropped stage="compute"   ×282
WARN victory_gpu::pipeline: shader does not translate; its pipelines' draws are dropped stage="mesh"      ×14
WARN victory_gpu::pipeline: shader does not translate; its pipelines' draws are dropped stage="vertex/pixel" ×17
INFO victory_gpu::host: dropped 64.0/frame without a host pipeline: indirect kind 0: prepare failed (compute false, mesh false)
INFO victory_gpu::host: dropped 5.0/frame without a host pipeline: compute a197f50cd8481541
INFO victory_gpu::host: dropped 5.0/frame without a host pipeline: compute c85822de2e41cfaa
INFO victory_gpu::host: dropped 5.0/frame without a host pipeline: mesh adc5c689b0552cc2
WARN victory_gpu::host: slow host list ms=52 commands=0
DEBUG victory_gpu::texture: a sampled texture's memory is all zero (not streamed yet, or a failed BCPack read)   (many, early frames)
```
**Questions**
1. Is the `dropped 64.0/frame … indirect kind 0: prepare failed` expected at this stage (the
   README says most of the scene is missing), or is it a separate defect worth a trace? The
   `prepare failed (compute false, mesh false)` reads like the arguments buffer's pipeline could
   not be resolved before the indirect call.
2. The 282 compute shaders that do not translate are presumably the `64-bit image atomic` and
   `scalar memory read as data` groups from the translate pass (the RaytracingResolve /
   InterpolateStrands family). Is there a list of shader hashes I should attach, or is a
   `VICTORY_SKIP_PIPELINES` run with those hashes the useful next data point?
3. Are the all-zero sampled textures a streaming-order problem (they are sampled before the
   streamer wrote them) or the failed BCPack reads?
4. Does `VICTORY_SHADER_LOOP_LIMIT` help world frame time on this title? At the default it is
   ~1 fps/frame here; I can measure a lower limit and report the difference if that is useful.
**Not tested:** NVIDIA, Series S mode, and other titles. The GPU hung hard once when entering the
world on a real device (the README warns about this); the run above is the one that got through.
**AI use:** written by an AI agent (DeepSeek Harness, `deepseek-flash`) from my run logs; the runs,
the hardware and the dump are mine. No game files are attached.
