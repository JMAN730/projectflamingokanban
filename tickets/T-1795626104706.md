**Result:** boot, first-boot screens, intro, menus and loading worked. It got into the world, where the picture was black as the README describes, and ran past 8,000 frames without a GPU failure. Exit 0 when I closed the window.

Without changes it stopped about 16 s after start, for two reasons:

1. **Packed 16-bit targets refused.** The `no host texture` errors for formats 86 (flags 5) and 115 (flags 1) at 2560x1440 are the same as in #89. Vulkan on this driver has no storage or color-attachment support for `A1R5G5B5` or `A4R4G4B4`. A local stand-in to R8G8B8A8 like #89 made both textures. #89 covers it.

2. **A title assert, `int3` at `title+0x4dcbc9d`, still fired after fix 1.** That function appends to a buffer. It checks `capacity - used < len` and does `int3; jmp` on overflow, so it is meant to go on under a debugger. At the crash it had `used = 0x17fb0` of `0x18000` (80 bytes free) and `len = 0x6c0` (1728 bytes). The caller is `title+0x4e52a83`. The title's Breakpad then tried to upload a minidump to `submit.backtrace.io`. `net.rs` blocked that and the process exited with code 3. I did not find what fills the buffer. It may be something Wine reports as larger than Windows does, such as display modes or devices, but I have not checked that.

   As an experiment I added a diagnostics-only switch to the vectored handler, `VICTORY_SKIP_BREAKPOINTS=1`. When the faulting byte is `0xCC` inside a `victory-image-*` module, it sets `Rip += 1` and continues; `int3` in our own code still crashes. With it, the same assert kept firing (I logged only the first 32) and everything else ran as described above. I can open a PR for the switch if it is useful.

**Wine-only test failures** (the same with and without my changes; `victory-gpu` unit tests on this GPU):
- `indirect::tests::argument_clamp_builds`: Wine's HLSL compiler says `E5005: Method 'Load' is not defined on type 'RWByteAddressBuffer'`, so the indirect-argument clamp shader cannot be built under Wine.
- `resource::tests::buffer_data_reaches_the_host_texture`: the read-back row comes back all zeros.
