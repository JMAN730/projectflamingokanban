## Question

Some lighting compute shaders use the console's BVH intersect instructions. They decode but fall into a catch-all refusal, so the whole program and every pass behind it is lost. For stage 1, does the translator (a) lower them as an unconditional miss so the program runs without ray-traced contribution, (b) emulate the intersection against title memory, or (c) keep refusing?

## Context

Correct ray-traced lighting is out of scope; the question is only what unblocks the passes that share these programs. `crates/victory-shader/src/emit/lower.rs`, image catch-all.
