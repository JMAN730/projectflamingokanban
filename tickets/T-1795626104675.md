## Work

Some console shaders spin until another lane writes data. When that data never arrives on the host, the loop runs to our limit and the driver declares the device hung. Measure device removals and picture differences on the reference machine at several values of `VICTORY_SHADER_LOOP_LIMIT`, and set the default accordingly.

## Done when

The measurements are posted, the default is changed (or confirmed) with the reasoning in the commit, and the `// shortcut:` comment at the limit says what it trades away.

## Context

The limit is part of the shader cache key, so each value translates afresh. A pixel shader helper lane spinning in a first-active-lane loop is one known case.
