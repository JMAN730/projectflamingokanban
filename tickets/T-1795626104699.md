## Work

271 vertex and pixel programs are refused over interpolation: "an interpolation with computed barycentrics" (207, at I/O raising), "barycentrics read directly" (36), "the first half of an interpolation" (28). Lower them: when the program computes its own barycentrics or reads them as values, interpolate by hand from per-vertex values instead of asking the host to.

## Done when

The three reasons fall on the scoreboard, and a hardware test compares hand interpolation with the host's for perspective, linear and centroid modes.

## Context

`crates/victory-shader/src/io.rs` raises stage I/O; `emit/lower.rs` holds the pixel input refusals.
