### Bug

In `crates/victory-gpu/src/primitive.rs` (`f32_to_half`):

```rust
let exp = ((bits >> 23) & 0xff) as i32 - 127 + 15;
let man = bits & 0x7f_ffff;
if exp >= 31 {
    return sign | 0x7c00; // too large: infinity
}
...
let half = (exp as u32) << 10;
sign | (half + ((man + 0x1000) >> 13)) as u16
```

Two IEEE-754 binary32-to-binary16 bugs occur during rectangle-list vertex expansion for `F16` elements:

1. **NaN becomes ±Infinity:** `raw_exp == 0xff` with `man != 0` produces `exp = 143 >= 31` and returns `sign | 0x7c00` (`+inf` / `-inf`) instead of a quiet NaN, even though `half_to_f32` right above preserves NaNs.
2. **Normal rounding ties away from zero instead of to even:** `(man + 0x1000) >> 13` rounds ties (e.g. `1.0 + 2^-11 = 0x3f80_1000`) up to odd `0x3c01` instead of even `0x3c00`, contradicting IEEE-754 and the subnormal branch directly above it (which explicitly rounds ties to even).

### Fix

- Handle `raw_exp == 0xff && man != 0` before `exp >= 31`, returning `sign | 0x7e00 | (man >> 13) as u16` (quiet NaN preserving sign and upper payload bits, and keeping sNaNs with payload below bit 13 as NaN rather than infinity).
- Use IEEE-754 round-to-nearest-even for normals: `let lsb = (man >> 13) & 1; sign | (half + ((man + 0x0fff + lsb) >> 13)) as u16`.
- Added synthetic unit test `primitive::tests::f32_to_half_preserves_nan_and_rounds_normals_to_nearest_even` covering qNaN/sNaN (both signs + payload), infinities, normal ties to even/odd, overflow boundaries, and exhaustive round-trip across all 65,536 `u16` f16 bit patterns.

### Verification

- **Before fix:** `f32_to_half_preserves_nan_and_rounds_normals_to_nearest_even` failed on NaN (`f32_to_half(0x7fc00000) = 0x7c00, want 0x7e00`) and on normal ties to even.
- **After fix (Windows 11):**
  - `cargo test -p victory-gpu`: 51 passed, 0 failed, 1 ignored.
  - `cargo test -p victory-gpu --features diagnostics`: 54 passed, 0 failed, 1 ignored.
  - `cargo clippy -p victory-gpu --all-targets -- -D warnings` (default and `--features diagnostics`): clean.
  - `cargo check -p victory --features diagnostics`: clean.
  - `rustfmt --edition 2024 --check crates/victory-gpu/src/primitive.rs`: clean.
  - `cargo xtask policy`: 154 files ok.
