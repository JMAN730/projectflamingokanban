## The problem

`VICTORY_CAPTURE` must name a folder that already exists. If it doesn't, every frame fails with `frame not saved ... The system cannot find the path specified. (os error 3)` and the run saves nothing. `VICTORY_DUMP_TARGETS` writes into the same folder, so it is affected too.

## The change

The folder and any missing parents are created when capturing starts. If that fails, a `capture folder not made` warning is logged.

## Tested

- New test `a_missing_capture_folder_is_made`.
- Both of CI's clippy configurations pass. `cargo test --workspace --locked` passes (342). `cargo xtask policy` passes.
- Ran the title (1.0.2.1, diag build, RTX 3090) with `VICTORY_CAPTURE` set to a nested folder that didn't exist:
  - Before the fix: every frame logged `frame not saved`.
  - After the fix: the folder was created and 10 frames were saved.

No game data in the change.
