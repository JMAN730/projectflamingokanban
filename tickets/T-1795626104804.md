### RX 9070 XT: main + 182 open PRs reaches `story000`, then GPU page faults 2–6 min in the world

**Setup**
- GPU: AMD Radeon RX 9070 XT (RDNA4)
- CPU: Ryzen 7 7800X3D, 32 GB · Windows [11]
- Build: `main` `d2a4bae` + 182 open PRs (list attached, in merge order), `diag` profile with
  `--features diagnostics`
- `main` alone on this machine: reaches the loading screens

**Summary**
With the 182 PRs, the title boots, shows the loading screens correctly, loads `story000` and
runs in the world for 2–6 minutes at **1–2 fps** (700–4,600 draws/frame, **130–2,000
dropped/frame** for untranslated shaders). Every run then ends in a **host GPU page fault**
at an address outside all title memory copies and heaps. The fault address and timing differ
between runs.

**GPU failure (3 runs, `VICTORY_D3D12_DRED=1`)**
| Run | In world before fault | Notes |
|---|---|---|
| 1 | ~5.5 min | fault right after first bind of compute `e6a32775a6bb91c8` (its table: `Uav s1+8: uav None`, `u6 heap index 64: null`) |
| 2 | ~5.5 min, same moment | `VICTORY_SKIP_PIPELINES=e6a32775a6bb91c8`: same fault point; the same 22 pipelines are first bound in the 20 s before it in runs 1 and 2 |
| 3 | ~2 min | skip `e6a32775a6bb91c8,eeed82b877b44b5f`: faults earlier |

Each fault message reads "page fault at 0x…; the nearest title memory copy below it …;
view heap … past its end". The display driver resets each time.

**With GPU-based validation (`VICTORY_D3D12_DEBUG=1`, `VICTORY_D3D12_GBV=1`)**
- **No out-of-range descriptor reports and no GPU fault**, so the faults probably come from
  raw address reads rather than heap indices.
- 7× `SRV resource dimensions differs`: shader expects `TEXTURE2D`, descriptor is
  `TEXTURE1D`, pipelines `[mesh d4111a6e6ea49d91, pixel c0a7fe77b1862e10]` and
  `[vertex 089d6271be6650ef, pixel fa455c8a3c32577b]`.
- About 50 s into the world, the **title** crashed instead: `0xc0000005` write to `0x0` at
  image `+0x23cf683` (stack `+0x2215c35`, `+0x2215eca`). Its crash reporter's upload to
  backtrace.io was blocked by the HLE net module, as intended.

**Untranslated shaders in the world (one run, by reason)**
