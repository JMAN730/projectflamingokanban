Specs

- GPU: AMD Radeon RX 7700 XT, 12 GB VRAM
- AMD Software: Adrenalin Edition 26.11.2
- CPU: R5 5600X
- RAM: 32 GB
- OS: Windows 11 (10.0.26100 Build 26100)

After loading screen, when some audio of the characters start playing the game sometimes freezes for a few seconds and then continues (all of this in black screen) at some point the initial credits show up and even for a second an image from this credits but instantly black screen again until GPU driver crashes which makes the game crash.

I attach the crash log and a video of the whole run with GPU and CPU usage.

The README mentions this was tested on an RX 6700 XT. This report is from an RX 7700 XT, in case it helps to compare. Also it says that the GPU fails within seconds of entering the world. On this card it takes about 2.5 minutes (0:53 to 3:30 in the video), and some of the game's own screens (credits, two images) render briefly before the final freeze.
