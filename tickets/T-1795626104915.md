## Original body

`check_feature_support` in `crates/victory-gpu/src/device.rs` implements five feature IDs but only feature 2 (FEATURE_LEVELS) has a unit test. Features 0 (D3D12_OPTIONS), 1 (ARCHITECTURE), and 4 (MULTISAMPLE) are implemented and return values that titles read to decide which GPU features to enable — but no assertion verifies any of them.

## Untested features

**Feature 0 — D3D12_OPTIONS** (`device.rs`, ~line 230):
```rust
const OPTIONS: [u32; 16] = [
    1,  // double-precision shader operations
    1,  // output-merger logic operations
    2,  // minimum precision: 16-bit
    3,  // tiled resources tier
    3,  // resource binding tier
    1,  // stencil reference from pixel shaders
    1,  // typed UAV loads of more formats
    1,  // rasterizer-ordered views
    3,  // conservative rasterization tier
    40, // GPU address bits per resource
    0,  // 64 KiB standard swizzle
    0,  // console-only field
    0,  // cross-node sharing tier
    0,  // cross-adapter row-major textures
    1,  // viewport and render target index from any stage
    2,  // resource heap tier
];
```
This 16-word array advertises RDNA2 capabilities. A silent edit to any tier value could make a title disable a valid feature or crash on a capability mismatch.

**Feature 1 — ARCHITECTURE** (~line 297):
```rust
// Not tile-based; unified, cache-coherent memory.
a[1..].copy_from_slice(&[0, 1, 1]);
```
Returns `[node, tile-based=0, unified=1, cache-coherent=1]`. Non-zero `node` returns `E_INVALIDARG`.

**Feature 4 — MULTISAMPLE** (~line 316):
```rust
q[3] = u32::from(matches!(q[1], 1 | 2 | 4 | 8));
```
Quality level count: 1 for sample counts 1/2/4/8, 0 for others. The title queries this before allocating multisampled render targets.

## Missing test

The only test, `feature_levels_pick_the_highest_supported` in `device.rs` tests, calls `check(device, 2, ...)` exclusively. The function slots for features 0, 1, and 4 share the same VTable slot as feature 2, confirming they all go through `check_feature_support` — but only feature 2 is exercised.

## Suggested tests

Add three test functions in the `#[cfg(test)]` block of `device.rs`:

```rust
#[test]
fn feature_options_reports_rdna2_caps() {
    let device = device();
    let check = slot::<extern "system" fn(This, u32, *mut c_void, u32) -> HRESULT>(device, 0x68);
    let mut opts = [0u32; 16];
    assert_eq!(check(device, 0, opts.as_mut_ptr().cast(), 64), S_OK);
    // spot-check key tier values
    assert_eq!(opts[0], 1, "double-precision shader support");
    assert_eq!(opts[3], 3, "tiled resources tier 3");
    assert_eq!(opts[4], 3, "resource binding tier 3");
    assert_eq!(opts[8], 3, "conservative rasterization tier 3");
    assert_eq!(opts[9], 40, "GPU address bits per resource");
    assert_eq!(opts[15], 2, "resource heap tier 2");
    // wrong size returns E_INVALIDARG
    assert_eq!(check(device, 0, opts.as_mut_ptr().cast(), 60), E_INVALIDARG);
}

#[test]
fn feature_architecture_is_unified_cache_coherent() {
    let device = device();
    let check = slot::<extern "system" fn(This, u32, *mut c_void, u32) -> HRESULT>(device, 0x68);
    let mut arch = [0u32; 4]; // node 0
    assert_eq!(check(device, 1, arch.as_mut_ptr().cast(), 16), S_OK);
    assert_eq!((arch[1], arch[2], arch[3]), (0, 1, 1), "not tile-based, unified, cache-coherent");
    arch[0] = 1; // non-zero node
    assert_eq!(check(device, 1, arch.as_mut_ptr().cast(), 16), E_INVALIDARG);
}

#[test]
fn feature_multisample_counts_quality_levels() {
    let device = device();
    let check = slot::<extern "system" fn(This, u32, *mut c_void, u32) -> HRESULT>(device, 0x68);
    let query = |sample_count: u32| {
        let mut q = [0u32, sample_count, 0, 0];
        check(device, 4, q.as_mut_ptr().cast(), 16);
        q[3]
    };
    assert_eq!(query(1), 1, "1-sample: supported");
    assert_eq!(query(4), 1, "4-sample: supported");
    assert_eq!(query(3), 0, "3-sample: not supported");
    assert_eq!(query(16), 0, "16-sample: not supported");
}
```

`cargo test -p victory-gpu` — all three pass without game data or GPU hardware.
