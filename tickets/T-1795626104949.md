### Summary
Fixes 8 real overflow/underflow, buffer-lookup, and snapshot-consistency bugs in `crates/victory-gpu/src/shadow.rs` (previously 0 unit tests) and adds 8 synthetic regression tests proving each invariant.

Because external PR creation is currently restricted (`collaborators_only`), the CI-green branch is ready on my fork for cherry-pick / review:
- **Branch**: `geiyiliyabumo/VIctory@test/gpu-shadow-tests`
- **Commit**: `geiyiliyabumo/VIctory@c1dd5b1` (based on `main` `ffe310e`)

### Bugs Fixed (`crates/victory-gpu/src/shadow.rs`)
1. `register`: `start + len` `u64` overflow -> `checked_add` (reject overflowing registrations).
2. `loose`: window `next_multiple_of` overflow -> `checked_next_multiple_of` + `checked_sub`.
3. `find`: `.take(64)` could stop before reaching an earlier covering buffer -> unbounded start-descending scan.
4. `find`: equal-start buffers could return a larger covering buffer instead of the tightest -> choose smallest `end` among equal starts.
5. `refresh`: `start + len - address` underflow when `address` is past end -> use `self.left(address)`.
6. `inside` / `writing` / `copy_back` / `update`: `address + len` `usize` overflow -> `saturating_add`.
7. `writing`: newly declared gap retained stale baseline -> re-snapshot declared range and dedupe via `pending`.
8. `copy_back`: overlapping copy-backs could replay an earlier CPU edit -> refresh snapshot after copy-back.
