## Original body

AMD report; every GPU issue here so far is NVIDIA or Intel.

**Hardware:** Windows 11 (26300), Ryzen 7 5700X3D, 32 GB, AMD Radeon RX 9070 XT (RDNA4, gfx1201), driver 32.0.32029.2010 (Adrenalin 26.11.2), ReBAR on, 2560x1440.

**Build:** `main` at `b99f876`, `cargo build --profile diag -p victory --features diagnostics`, Rust 1.98.1, MSVC 19.44. Release build identical.

**Command:** `victory.exe run <game dir>\game_scarlett_master.exe --execute` with `VICTORY_D3D12_DRED=1`, `VICTORY_CAPTURE=<dir>`, `VICTORY_KEYS=25:Enter,35:Enter,45:Enter,55:Down,62:Enter,70:Enter`.

**Result:**

| | |
|---|---|
| Loader | five modules mapped, `0 missing` imports each (`game_scarlett_master.exe`: 88 hle, 427 host, 72 title) |
| Screen reached | first-boot account picker, 1920x1080, text renders correctly |
| Frame rate | 30.0 fps, 33.3 ms/frame, 21 draws/frame, sustained 4 min (48 samples) |
| Shaders | 11 translated; on a second run `hits=11 misses=0` from cache |
| Device loss | none — no `DXGI_ERROR_DEVICE_HUNG`, no device removed, no DRED output, no `crashes.log` |
| Display | no reset |

#11 (RTX 4060) and #16 (RTX 5070 Ti) lose the device during the same first-boot screens. On this GPU the menus hold.

**Warnings:**

```
WARN victory_hle::modules::kernel: a host DLL outside the host policy: refused dll="rpcrt4.dll"
WARN victory_gpu::object: method not implemented object="device" slot=0x218 caller="+0x24800db"
WARN victory_gpu::object: method not implemented object="device" slot=0x1c8 caller="+0x247757e"
WARN victory_gpu::descriptor::host: view the host does not allow unordered=true format=53 flags=2
WARN victory_gpu::queue: a black frame after a frame that was not frame=1 resource=0x1fd72
WARN victory_gpu::queue: levels after the black frame frame=7 levels=[0, 0, 0, 0, 0, 0, 0]
```

The frame=1 black frame and frame=7 levels warnings reproduce on both the software adapter and the GPU, and may be the startup flicker #20 targets.

**Not tested:** loading and the world. Synthetic keys do not move the account picker — `VICTORY_KEYS` produces no visible change and no pad log line — so those stages need a real controller. World rendering is untested on AMD.
