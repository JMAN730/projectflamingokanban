## Original body

On main `d2a4bae1`, I reproduced a stale read through the guest command-list and queue tables with the diagnostics build on Microsoft WARP. The list's 64-bit memory wait currently returns immediately. PR #32 implements queue fence waits and explicitly leaves this separate command-list method open.

## Synthetic reproduction

Create two guest direct queues, one closed list on each, and three live 64-bit words initially zero. Keep the lists, queues, and words alive throughout.

1. The producer list records bottom-of-pipe value writes of `0x5a55a11c` into the payload and `2` into the counter, in that order.
2. The consumer list records a 64-bit wait for the counter to be greater than or equal to `1`, then copies eight bytes from the payload to the result.
3. Submit both through ExecuteCommandLists. Run once producer-first and once consumer-first on fresh objects.

| Submission order | Final counter | Final payload | Result |
| --- | ---: | ---: | ---: |
| Producer first | 2 | 0x5a55a11c | 0x5a55a11c |
| Consumer first | 2 | 0x5a55a11c | 0 |

Once the producer completes and releases the consumer, the expected result is `0x5a55a11c` in both cases. Blocking the submitting CPU thread at the first Execute would deadlock the consumer-first case. A wait in the middle of a list also needs to preserve work before it.

## ABI evidence

On retail build 1.0.2.1, I found two call sites on the newer list layout that pass comparison 7 and a full-width reference. They supply a 32-bit trailing argument of 0 and 1 respectively. This agrees with the [XCL 64-bit implementation](https://github.com/ivall/xcl/blob/beaa245ca04e212f064efc7cafcdce104bc5c0a2/crates/xcl/src/hle/d3d12x/list_x.rs#L2459-L2470), which compares the full word. The 32-bit command has a distinct signature.

This establishes a command-ordering regression with synthetic data. Its contribution to the black frame or device removal in #71 is unmeasured. No title run or game data was needed for the reproduction. AI-assisted investigation and verification with Codex.
