## The demo

[tibzejoker/VIctory](https://github.com/tibzejoker/VIctory) is a fork of `main` with any%5 installed. Its merge queue runs the same checks as your CI (`windows-latest`, `cargo clippy -D warnings`, `cargo test --workspace --locked`), and it is green on your current `main`. Nothing else in the code changed.

## What any%5 is

[any%5](https://github.com/tibzejoker/anyPercent5) is a small tool for projects that get more pull requests than their maintainers can read. It runs on GitHub alone (an Action, an inbox issue and a ledger branch, no server):

- A contributor sends a change with `anyp5 submit`. It does not appear as a pull request.
- The change goes to a few other contributors picked at random, who review it without knowing who wrote it. Known-bad "canary" changes are mixed in, so a reviewer who approves everything loses their review weight.
- Approved changes are batched onto an `anyp5-queue` branch, the project's own tests run there, and the main branch only moves when the run is green.
- Maintainers keep the direction: they open tasks, can veto, and can still push themselves.
