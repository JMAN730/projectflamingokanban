### Changes
- **`crates/victory-hle/src/runtime.rs`**:

  - Added 5 unit tests (6 total): IID data binding, case-insensitive `d3d12_xs.dll` serving, export set + `Provenance::Hle` resolution, `device::IID` export pointer, and `D3D12XboxCreateDevice` null-arg `E_INVALIDARG` rejection.
