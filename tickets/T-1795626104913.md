## Original body

All twelve `s_cmpk_*` SOPK scalar comparison instructions are implemented in `crates/victory-shader/src/emit/lower.rs` but have no hardware test using `build_valu_cs` and `run_cases` in `crates/victory-shader/src/emit/valu_tests.rs`.

## Implementation evidence

`lower.rs`, `sop()`, handles both `s_cmp_*` SOPC and `s_cmpk_*` SOPK in a shared branch:

```rust
if let Some(op) = name.strip_prefix("s_cmp_").or(name.strip_prefix("s_cmpk_")) {
    let (a, b) = if name.starts_with("s_cmpk_") {
        let b = if op.ends_with("_i32") {
            // sign-extend the 16-bit immediate to i32
            self.s.m.i32(i32::from(imm.unwrap_or(0) as i16) as u32)
        } else {
            // zero-extend for unsigned
            self.s.m.i32(u32::from(imm.unwrap_or(0)))
        };
        (src32(self, 0)?, b)
    } else {
        (src32(self, 0)?, src32(self, 1)?)
    };
    let p = match &op[..2] { "eq" => pred::EQ, "lg" => pred::NE, … };
    let r = self.s.m.cmp(c, p, a, b);
    self.set(scc, Val::Bit(r));
    return Ok(());
}
```

The SIMM16 sign-extension (`i32::from(imm as i16)`) only runs for `s_cmpk_*i32` variants and is not shared with any other tested instruction.

## Missing test

`valu_tests.rs` contains no call to `build_valu_cs` with any `s_cmpk_*` word. The SOPK encoding puts the opcode and source register in the high 16 bits and the signed 16-bit immediate in the low 16 bits:

```
SOPK word: 0xB000_0000 | (op << 23) | (ssrc << 16) | (simm16 & 0xFFFF)
```

For example, `s_cmpk_gt_i32 s0, -1` = `0xB500_FFFF` (op=0x5=s_cmpk_gt_i32 at SOPK position, ssrc=0, simm16=0xFFFF=-1).

## Critical edge case

`s_cmpk_gt_i32 s0, -1` checks whether s0 > -1 (i.e., s0 >= 0). If sign-extension were missing (treating `0xFFFF` as `+65535` instead of `-1`), all small positive values would compare incorrectly. This is the same class of sign-extension risk that was verified for `s_bfe_i32` in `bfe_signed_and_unsigned_match_rdna2`.

## Suggested test

Add `fn s_cmpk_matches_s_cmp()` to `valu_tests.rs`. The result is in SCC; reading it back requires `v_cndmask_b32` from `s6`:

```rust
#[test]
fn s_cmpk_matches_s_cmp() {
    // Helper: build a 1-instruction SOPK shader that writes SCC, then read via v_cndmask.
    // SOPK encoding: upper 16 = 0xB000 | (op << 7) | ssrc; lower 16 = simm16.
    let sopk = |op: u32, ssrc: u32, simm16: i16| -> u32 {
        0xB000_0000 | (op << 23) | (ssrc << 16) | ((simm16 as u16) as u32)
    };
    let make = |word: u32| build_valu_cs(&[
        word,
        vop3(0x101, 0, 0x80, 0x81, sgpr(6))[0], // v_cndmask_b32 v0, 0, 1, s6
        vop3(0x101, 0, 0x80, 0x81, sgpr(6))[1],
    ]);

    // s_cmpk_eq_i32 s0, 5: s0 == 5 → 1, else 0
    let eq_i = make(sopk(0x3, 0, 5));
    // s_cmpk_gt_i32 s0, -1: s0 > -1 → 1 for s0=0, s0=1; 0 for s0=-1, s0=-2
    let gt_i = make(sopk(0x5, 0, -1));
    // s_cmpk_lt_u32 s0, 10: s0 < 10 (unsigned) → 1 for 0..9, 0 for 10..
    let lt_u = make(sopk(0xd, 0, 10));

    // Cases: [s0 value in inp[0]]
    run_cases(&eq_i, &[[5, 0, 0, 0], [4, 0, 0, 0], [0, 0, 0, 0]], |backend, i, inp, got| {
        let want = if inp[0] == 5 { 1u32 } else { 0 };
        assert_eq!(got, want, "{backend}: s_cmpk_eq_i32({}, 5) = {got}", inp[0] as i32);
    });
    run_cases(&gt_i, &[[0u32, 0, 0, 0], [1, 0, 0, 0], [(-1i32) as u32, 0, 0, 0], [(-2i32) as u32, 0, 0, 0]], |backend, i, inp, got| {
        let want = if (inp[0] as i32) > -1 { 1u32 } else { 0 };
        assert_eq!(got, want, "{backend}: s_cmpk_gt_i32({}, -1) = {got}", inp[0] as i32);
    });
    run_cases(&lt_u, &[[0, 0, 0, 0], [9, 0, 0, 0], [10, 0, 0, 0], [0xFFFF, 0, 0, 0]], |backend, i, inp, got| {
        let want = if inp[0] < 10 { 1u32 } else { 0 };
        assert_eq!(got, want, "{backend}: s_cmpk_lt_u32({}, 10) = {got}", inp[0]);
    });
}
```

The test skips gracefully when no SM 6.6 device is available and runs on WARP. No game data needed.
