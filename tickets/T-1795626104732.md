## Original body

### Summary

With indirect execution on, every world frame drops about **246 `ExecuteIndirect` draws per frame whose topology is the console's rectangle list** (17). `State::execute_indirect` refuses `DRAW | INDEXED` when `self.topology == RECTANGLES`, because rectangles are expanded on the CPU (`primitive::expand_rects`) and an indirect draw's vertex count is only known on the GPU.

The opening cutscene then shows its intro card and subtitles, with audio, but the picture behind them stays black. As the `primitive` module notes, the title draws its full-screen passes as rectangles, so these dropped draws are a likely cause of the black picture. That is not proven.

### Setup

- RX 7800 XT 16 GB, driver 32.0.32015.7029, Windows 11 26200, 31.6 GB RAM
- `diag` build of `main` `d2a4bae` + #135 + #242 + #230 + #124 + #130, Series X mode, v1.0.2.1

### Data (diagnostics drop summary, world frames)

```
dropped 256.0/frame without a host pipeline: indirect kind 0: pipeline mismatch (compute false, mesh false, topology 17)
```

That reason averages **246 per frame** over the run, and it is the only indirect drop reason the summary names. For scale, a typical world frame line:

```
1.2 fps, 864.9 ms/frame (...), 3348 draws/frame, dropped 783 without a host pipeline (0 being made) and 1294 indirect
```

So the rectangles are about 250 of the 1,300–2,600 indirect executions dropped per frame. The rest belong to pipelines that have no host pipeline: shaders that don't translate, or that the host refuses.

### Possible directions (not tried)

- Expand rectangle indirect draws on the GPU. Clamp the record to `6 * (vertexCount / 3)` vertices, and fetch the fourth corner in the vertex shader (`v0 + v2 - v1`) when the pipeline's inputs allow it.
- For pipelines without per-vertex inputs (vertex ID only), a vertex-ID remap pass.

I can rerun with a diagnostics switch if that helps narrow it, e.g. counting which pipelines the dropped rectangle draws use.
