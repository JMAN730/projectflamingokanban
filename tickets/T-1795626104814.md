## Original body

## Problem
On Windows 10 the title crashes during Game Init (frame 0). Just before the
crash, the host refuses several root signatures:

    WARN victory_gpu::pipeline::host: root signature:
    Unsupported bit-flag set (root signature flags c01).
    WARN victory_gpu::pipeline::host: host root signature refused
    error=E_INVALIDARG (0x80070057)

followed by:

    unhandled exception 0xc0000005 at victory-image-...dll+0xb5a5f8 (read 0x68: nothing mapped there)

Flags 0x400/0x800 (CBV_SRV_UAV_HEAP_DIRECTLY_INDEXED /
SAMPLER_HEAP_DIRECTLY_INDEXED) need SM 6.6 dynamic resources, which the inbox
D3D12 runtime on Windows 10 does not support. The README lists Windows 10 as
supported.

## Fix that worked for me
Enabling the D3D12 Agility SDK (Microsoft.Direct3D.D3D12 1.620.2):

apps/victory/src/main.rs:

    #[unsafe(no_mangle)]
    pub static D3D12SDKVersion: u32 = 620;

    #[unsafe(no_mangle)]
    pub static D3D12SDKPath: &[u8; 9] = b".\\D3D12\\\0";

apps/victory/build.rs:

    println!("cargo:rustc-link-arg-bins=/EXPORT:D3D12SDKVersion");
    println!("cargo:rustc-link-arg-bins=/EXPORT:D3D12SDKPath");

and copying D3D12Core.dll and d3d12SDKLayers.dll from the NuGet package
(build/native/bin/x64) into target/release/D3D12/.

With this, the root signature warnings are gone and the title gets past Game Init.

It might be worth adding this to the project (or documenting it), since the
README lists Windows 10 as supported.

## System
- Windows 10 (build: 22H2 19045.7846)
- NVIDIA RTX 3060, driver 621.01
- Title version 930.048.020

### Comment 2 — @LAKSHYA-cmd-tech — 2026-11-24T10:17:55Z

Regarding root signature refusal on Windows 10 (`Unsupported bit-flag set (root signature flags c01)`):

In addition to Agility SDK activation, we have implemented an in-engine fallback path in `crates/victory-gpu/src/pipeline/host.rs`:
If the host runtime refuses versioned root signature serialization or creation due to `0xC01`/`0xC00` (`D3D12_ROOT_SIGNATURE_FLAG_CBV_SRV_UAV_HEAP_DIRECTLY_INDEXED | D3D12_ROOT_SIGNATURE_FLAG_SAMPLER_HEAP_DIRECTLY_INDEXED`), `root_signature()` catches `E_INVALIDARG`, warns, and immediately retries without the directly-indexed flags.

Commit and verification available in:
`https://github.com/LAKSHYA-cmd-tech/VIctory/commit/df9ab3c69172c64cd8638344390577334954bd04`


### Comment 3 — @Sunkiller-qc — 2026-11-24T12:54:11Z

This is #84: Windows 10's in-box D3D12 stops at SM 6.5, so root signatures with `CBV_SRV_UAV/SAMPLER_HEAP_DIRECTLY_INDEXED` are refused and the title then crashes at `+0xb5a5f8` (see #348 and #741). Loading the Agility SDK runtime, the way you did, is exactly what #175 does (`cargo xtask agility`).

The flag fallback branch mentioned above (#626) doesn't fix it on its own. On #828 the pipelines were still refused with it, and on #84 Zilumz1 got a PSO refusal when the flags were dropped. I'd close this as a duplicate of #84.
