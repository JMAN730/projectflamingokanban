## Work

On every vendor the G-buffer fills, the lighting passes are recorded and submitted, and the lighting target ends at exactly zero. Using the diagnostics build's capture and target switches on the reference machine, walk back from the lighting target to the first input that is wrong, and name the cause.

## Done when

The first wrong input is identified with the evidence (which pass, which resource, what it held against what it should hold, in words), and the fix is either made or split into a ticket.

## Context

Known necessary pieces, none sufficient alone: rectangle lists for tiled lighting, compute writes to depth and stencil, the gather level used by meshlet culling, wave64 groups past 64 threads, the BVH programs, typeless views. The research on the lit public tree narrows where to look. Needs the game and the hardware.
