### Summary
Fixes a real access-violation crash (`0xc0000005` in `d3d12.dll`) in `create_deserializer` in `crates/victory-gpu/src/root.rs` and expands deterministic synthetic unit tests from 3 to **11 passing tests**.

Because external PR creation is currently restricted (`collaborators_only`), the CI-green branch is ready on my fork for cherry-pick / review:
- **Branch**: `geiyiliyabumo/VIctory@test/gpu-root-audit`
- **Commit**: `geiyiliyabumo/VIctory@ef0c3e9` (based on `main` `ffe310e`)

### Changes (`crates/victory-gpu/src/root.rs`)
- **Bug fix**: `create_deserializer` previously forwarded a null `riid` straight to host `D3D12CreateRootSignatureDeserializer`, crashing with `STATUS_ACCESS_VIOLATION`. It now rejects null blob, `size == 0`, null `riid`, and null `out` with `E_INVALIDARG` before calling the host.
- **Tests (3 -> 11 synthetic)**: covers ABI layout of `Desc`/`VersionedDesc`, console-flag masking, null-desc rejection on both serializers, deserializer null-arg crash regression, `create` IID/null-out probing, all 3 IIDs + refcount lifecycle, vtable slots `0x28`/`0x30`/`0x38`, and host rejection of truncated/garbage blobs.
