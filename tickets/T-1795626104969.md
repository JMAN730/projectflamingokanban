---

### 1. Correctness of Bug Fixes

#### A. TLS Directory & Index Bounds (`crates/victory-loader/src/tls.rs`)
- **Vulnerability**: Untrusted PE headers could supply an `AddressOfIndex` pointing outside the image mapping (or near the end of address space). Previously, `redirect` performed an unchecked dereference and write (`index_at.write(0)`), potentially corrupting host memory or crashing with an access violation.
- **Bounds check**: Validating `directory + TLS64_ADDRESS_OF_INDEX + size_of::<usize>() <= size` prevents running past image boundaries when reading the directory entry.
- **Empty Section Protection**: `VirtualProtect` strictly rejects `dwSize == 0` with `ERROR_INVALID_PARAMETER` (`87`). Skipping sections where `virtual_size == 0` avoids aborting redirects on images containing empty placeholder sections (e.g. metadata or discardable debug headers).
- **Index Range**: Bounding `index <= MAX_INDEX` prevents arithmetic overflow when calculating thunk offsets (`index * 8`).

#### B. Robust Float Duration Parsing (`crates/victory-loader/src/stacks.rs`)
- **Panic Vector**: In `dump_stacks_on_schedule`, `Duration::from_secs_f64` unconditionally panics if `t` is `NaN`, `inf`, or exceeds the maximum representable `Duration` (`~1e19` seconds).
- **Delays Extraction**: `delays()` properly filters with `t.is_finite()` and `Duration::try_from_secs_f64(t.max(0.0)).ok()`.

---

### 2. Minor Hardening Recommendation (Integer Overflow Edge Case)
In `crates/victory-loader/src/tls.rs`:
```rust
let at = index_at as usize;
if at < base || at - base + size_of::<u32>() > size {
    bail!("_tls_index at {at:#x} is outside the image");
}
```
If `index_at` contains an arbitrary 64-bit value where `at >= base` and `at - base > usize::MAX - 4`, evaluating `at - base + size_of::<u32>()` will overflow and wrap around in release builds (or panic in debug builds).
To be completely watertight against arbitrary pointer values, consider bounds-checking without addition:
```rust
if at < base || at - base > size.saturating_sub(size_of::<u32>()) {
    bail!("_tls_index at {at:#x} is outside the image");
}
```
(or via `(at - base).checked_add(size_of::<u32>()).map_or(true, |end| end > size)`).
