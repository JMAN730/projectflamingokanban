## Original body

Structured-buffer accesses whose stride the shader analysis loses (`buffer_load_dword ... idxen`, `buffer_store_dword ... idxen`, atomics) currently fail translation (`a structured buffer of unknown stride`, 36 programs in the world run) or, under `VICTORY_LOOSE_BUFFERS`, read the wrong element (raw view at the instruction offset).

The descriptor's stride is known at bind time (`D3D12_BUFFER_SRV.StructureByteStride`, parsed today by `descriptor/host.rs`'s element()) but there is no channel to the shader: the console S# is virtualized into a heap handle, so the emitted DXIL cannot compute `index * stride`.

Design (full note + anchors in `docs/runtime-stride.md` on branch `sync`):

1. `victory-shader`: a stride-table root SRV (`t0, space STRIDE_SPACE`), one dword per host view-heap slot; at the three "unknown stride" sites emit `slot = heap_index(load, first)`, `stride = rawBufferLoad(table, slot * 4)`, `address = index * stride + off`. `HostShader` gains the table as a root SRV.
2. `signature.rs` / `pipeline/host.rs`: declare and bind the table.
3. `descriptor/host.rs` / `draw.rs`: keep `slot -> StructureByteStride` in sync with the heap (4 bytes per slot) and write it when a view is placed.

Success criterion: the 36 `unknown stride` translations disappear, and the AMD iGPU world run (`VICTORY_D3D12_ADAPTER=amd`, `VICTORY_D3D12_DRED=1`) no longer faults at `0x3598000` (or the fault moves to the next producer).

Context: on the iGPU the world reaches 1178 draws/frame with native wave64 (`host wave lanes min=32 max=64`, compute refusals 0) and then faults with `page fault at 0x3598000` and NaN CBV constants — the garbage comes from the passes whose shaders are dropped. On NVIDIA the same garbage ends in `DEVICE_HUNG` (see #71).

Rechecked against the current upstream `main` (`d2a4bae`) using the local game shader archive and `translate --validate --jobs 8` (CPU-only; no game executable or GPU pipeline was launched). This run found 26,503 containers / 26,084 programs, emitted 22,156 DXIL containers, and validated 21,971.

The refusal `a structured buffer of unknown stride` accounts for 117 programs in this archive. The three refusal sites are in `crates/victory-shader/src/emit/lower.rs` around lines 5908, 5991, and 6052. The descriptor index flows through `heap_index`; host heap mirroring is in `crates/victory-gpu/src/descriptor/host.rs::HostHeap::mirror`, and `crates/victory-gpu/src/draw.rs::State::tables` can remap descriptor tables into dynamic slots.

This gives an up-to-date corpus check for the proposed runtime stride channel. I am checking the raw-view and dynamic-slot semantics before sending an implementation PR, so the extra byte-address calculation does not silently change how structured, typed, or raw descriptors are interpreted.
