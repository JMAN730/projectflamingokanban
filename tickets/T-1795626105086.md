## Original body

**What happens.** `ID3D12PipelineLibrary1::LoadPipeline` refuses every mesh pipeline with `E_INVALIDARG`. With the D3D12 debug layer on it is message 972, "The pipeline state desc provided does not match the one used to create the PSO stored with name …". It does so with the description that created the PSO, passed right after `StorePipeline` succeeded. Graphics and compute pipelines load back. So the library has never served a mesh pipeline: each is compiled in every run, stored again (refused, message 970 "already exists"), and its entry stays in a library that only grows.

**In the game.** RTX 3070, Windows 11 build 26300, system D3D12 runtime 10.0.26100.10068, `main` at ffe310e, debug layer on. A run over the library the previous run wrote (early start of 1,800 pipelines):

| kind | loaded | compiled again | 970 "already exists" | 972 "does not match" |
|---|---|---|---|---|
| graphics | 551 | 0 | 0 | 0 |
| compute | 506 | 0 (105 were new) | 0 | 0 |
| mesh | **0** | **723** | 723 | 723 |

The 1,000 graphics and compute pipelines load in about 7 s; the 723 mesh pipelines are compiled over the next 55 s as the title creates them. An unmodified `main` logs them too (567 of 970 and 568 of 972 by the end of the early start). `host-pipelines.bin` is 231 MB here.

**Without the title.** The program below: trivial mesh (`ms_6_5`) and pixel shaders compiled with dxc, an empty root signature, a stream of root signature, MS, PS, render target formats, depth format and sample description. `CreatePipelineState`, `StorePipeline("m")`, then `LoadPipeline("m", <the same stream>)`: refused, before and after `Serialize`, in the same process. The graphics (VS + PS) and compute pipelines in the same program load. Output on the RTX 3070:

```
store:
  graphics: Ok(())
  compute:  Ok(())
  mesh:     Ok(())
load, same library, the descriptions that created them:
  graphics: loaded
  compute: loaded
  mesh: REFUSED El parámetro no es correcto. (0x80070057)
      D3D12: id=972 ID3D12PipelineLibrary::Load*Pipeline: The pipeline state desc provided does not match the one used to create the PSO stored with name "m".
after Serialize, from a library made of the blob:
  graphics: loaded
  compute: loaded
  mesh: REFUSED (0x80070057)
```

The same on:
- the system runtime on **WARP** (Microsoft Basic Render Driver), so it is not the NVIDIA driver;
- the **Agility SDK runtime 1.618.1** (`ID3D12SDKConfiguration1::CreateDeviceFactory`, `D3D12Core.dll` 1.618.1 loaded, checked) on the RTX 3070.

Also tried with a longer program, all refused: an explicit empty AS subobject; no PS; the ten subobjects VIctory hands over (blend, sample mask, rasterizer, depth-stencil, RT formats, DSV format, sample desc).

**Found on the way: padding.** The library compares descriptions byte for byte, and two of ours carried bytes that are not fields. The depth-stencil description is copied from the title's stream as it stands, and the two bytes between `StencilWriteMask` and `FrontFace` hold the title's stack: in one run 192 mesh pipelines differed from a copy of themselves only there, under one name. A mesh pipeline's stream has four unwritten bytes between the type and each eight-byte subobject. This is masked today by the problem above (mesh pipelines do not load either way), but it would bite as soon as they do.

**A fix on my fork** (pull requests are collaborators-only, so a branch): https://github.com/Pablo-Barros/VIctory/tree/gpu/pipeline-library, two commits on ffe310e. CI's two clippy commands and the workspace tests pass.
1. `0707260` zeroes that padding where the descriptions are read and built, and in the stream before it is handed over. Two tests: descriptions read from `0xff` bytes keep their fields and lose their padding; a stream with set values likewise.
2. `cae3f32` The first pipeline of a kind that is stored is loaded back at once. Refused, the library gets no more of that kind in the run, and says so once:
   `WARN host pipeline library refuses a mesh pipeline it just stored: mesh pipelines are compiled every run, none kept`
   Same cold run as above: 1 of message 970, 2 of 972, and the 1,051 graphics and compute pipelines still load.

**What this does not solve.** The mesh pipelines are still compiled in every run. That needs a runtime that loads them, or another cache. Old libraries keep their dead mesh entries (`ID3D12PipelineLibrary` cannot remove one); deleting `host-pipelines.bin` once reclaims the space.

I cannot tell whether it is the same with the AMD driver. On a second run, `host pipeline library saved … made=… loaded=…` tells: with 1,800 pipelines started early, `loaded` should be well over 1,000 if mesh pipelines load.

Written with Claude (Anthropic); the runs, the measurements and the program below are from this machine.

```rust
//! Does D3D12's pipeline library load a mesh pipeline it just stored?
//! Controls: a graphics pipeline and a compute one, treated the same.
//!
//! `DEBUG=1`: the D3D12 debug layer, its messages printed after each step.
//! `WARP=1`: the Microsoft Basic Render Driver instead of the default adapter.
//! The argument is the folder holding mesh.dxil, pixel.dxil, vs.dxil, cs.dxil,
//! made with dxc from the four one-line shaders below the program.
use std::ffi::c_void;
use windows::core::{HSTRING, Interface, PCWSTR};
use windows::Win32::Graphics::Direct3D::D3D_FEATURE_LEVEL_12_0;
use windows::Win32::Graphics::Direct3D12::*;
use windows::Win32::Graphics::Dxgi::Common::*;
use windows::Win32::Graphics::Dxgi::CreateDXGIFactory1;

/// A stream subobject: its type, then its description, pointer-aligned.
#[repr(C, align(8))]
struct Sub<T>(D3D12_PIPELINE_STATE_SUBOBJECT_TYPE, T);

#[repr(C)]
struct Mesh {
    root: Sub<*mut c_void>,
    ms: Sub<D3D12_SHADER_BYTECODE>,
    ps: Sub<D3D12_SHADER_BYTECODE>,
    targets: Sub<D3D12_RT_FORMAT_ARRAY>,
    dsv: Sub<DXGI_FORMAT>,
    samples: Sub<DXGI_SAMPLE_DESC>,
}

fn code(bytes: &[u8]) -> D3D12_SHADER_BYTECODE {
    D3D12_SHADER_BYTECODE { pShaderBytecode: bytes.as_ptr().cast(), BytecodeLength: bytes.len() }
}

fn make_root(device: &ID3D12Device, flags: D3D12_ROOT_SIGNATURE_FLAGS) -> ID3D12RootSignature {
    let desc = D3D12_VERSIONED_ROOT_SIGNATURE_DESC {
        Version: D3D_ROOT_SIGNATURE_VERSION_1_1,
        Anonymous: D3D12_VERSIONED_ROOT_SIGNATURE_DESC_0 {
            Desc_1_1: D3D12_ROOT_SIGNATURE_DESC1 {
                NumParameters: 0,
                pParameters: std::ptr::null(),
                NumStaticSamplers: 0,
                pStaticSamplers: std::ptr::null(),
                Flags: flags,
            },
        },
    };
    // SAFETY: a description of live data; the blob is read before it is released.
    unsafe {
        let mut blob = None;
        let mut err = None;
        D3D12SerializeVersionedRootSignature(&desc, &mut blob, Some(&mut err)).unwrap();
        let blob = blob.unwrap();
        let bytes = std::slice::from_raw_parts(blob.GetBufferPointer().cast::<u8>(), blob.GetBufferSize());
        device.CreateRootSignature(0, bytes).unwrap()
    }
}

fn drain(device: &ID3D12Device) {
    let Ok(queue) = device.cast::<ID3D12InfoQueue>() else { return };
    for i in 0..unsafe { queue.GetNumStoredMessages() } {
        let mut size = 0;
        if unsafe { queue.GetMessage(i, None, &mut size) }.is_err() || size == 0 {
            continue;
        }
        let mut buffer = vec![0u64; size.div_ceil(8)];
        let message = buffer.as_mut_ptr().cast::<D3D12_MESSAGE>();
        // SAFETY: a buffer of the size the queue asked for.
        if unsafe { queue.GetMessage(i, Some(message), &mut size) }.is_ok() {
            let m = unsafe { &*message };
            let text = unsafe { std::slice::from_raw_parts(m.pDescription, m.DescriptionByteLength) };
            println!("      D3D12: id={} {}", m.ID.0, String::from_utf8_lossy(text).trim_end_matches('\0'));
        }
    }
    unsafe { queue.ClearStoredMessages() };
}

fn report(what: &str, r: windows::core::Result<ID3D12PipelineState>) {
    match r {
        Ok(_) => println!("  {what}: loaded"),
        Err(e) => println!("  {what}: REFUSED {e}"),
    }
}

fn main() {
    if std::env::var_os("DEBUG").is_some() {
        let mut layer: Option<ID3D12Debug> = None;
        unsafe { D3D12GetDebugInterface(&mut layer) }.unwrap();
        layer.iter().for_each(|l| unsafe { l.EnableDebugLayer() });
    }
    let dir = std::env::args().nth(1).unwrap_or_else(|| ".".into());
    let read = |n: &str| std::fs::read(format!("{dir}/{n}")).unwrap_or_else(|e| panic!("{n}: {e}"));
    let (ms, ps, vs, cs) = (read("mesh.dxil"), read("pixel.dxil"), read("vs.dxil"), read("cs.dxil"));
    let (ms, ps, vs, cs) = (code(&ms), code(&ps), code(&vs), code(&cs));

    let mut device: Option<ID3D12Device> = None;
    if std::env::var_os("WARP").is_some() {
        let factory: windows::Win32::Graphics::Dxgi::IDXGIFactory4 = unsafe { CreateDXGIFactory1() }.unwrap();
        let mut chosen = None;
        for i in 0.. {
            let adapter: windows::core::Result<windows::Win32::Graphics::Dxgi::IDXGIAdapter1> =
                unsafe { factory.EnumAdapters1(i) };
            let adapter = match adapter {
                Ok(a) => a,
                Err(_) => break,
            };
            let desc = unsafe { adapter.GetDesc1() }.unwrap();
            if (desc.Flags & windows::Win32::Graphics::Dxgi::DXGI_ADAPTER_FLAG_SOFTWARE.0 as u32) != 0 {
                chosen = Some(adapter);
                break;
            }
        }
        let adapter = chosen.expect("no WARP adapter");
        unsafe { D3D12CreateDevice(&adapter, D3D_FEATURE_LEVEL_12_0, &mut device) }.unwrap();
    } else {
        unsafe { D3D12CreateDevice(None, D3D_FEATURE_LEVEL_12_0, &mut device) }.unwrap();
    }
    let device = device.unwrap();
    let mesh_device: ID3D12Device7 = device.cast().unwrap();

    let root = make_root(&device, D3D12_ROOT_SIGNATURE_FLAG_NONE);
    let root_graphics = make_root(&device, D3D12_ROOT_SIGNATURE_FLAG_ALLOW_INPUT_ASSEMBLER_INPUT_LAYOUT);

    // SAFETY: the descriptions point at live data.
    unsafe {
        let mut formats = D3D12_RT_FORMAT_ARRAY { NumRenderTargets: 1, RTFormats: [DXGI_FORMAT_UNKNOWN; 8] };
        formats.RTFormats[0] = DXGI_FORMAT_R8G8B8A8_UNORM;
        let g = D3D12_GRAPHICS_PIPELINE_STATE_DESC {
            pRootSignature: std::mem::transmute_copy(&root_graphics),
            VS: vs,
            PS: ps,
            BlendState: Default::default(),
            SampleMask: u32::MAX,
            RasterizerState: D3D12_RASTERIZER_DESC {
                FillMode: D3D12_FILL_MODE_SOLID,
                CullMode: D3D12_CULL_MODE_NONE,
                DepthClipEnable: true.into(),
                ..Default::default()
            },
            PrimitiveTopologyType: D3D12_PRIMITIVE_TOPOLOGY_TYPE_TRIANGLE,
            NumRenderTargets: 1,
            RTVFormats: formats.RTFormats,
            DSVFormat: DXGI_FORMAT_UNKNOWN,
            SampleDesc: DXGI_SAMPLE_DESC { Count: 1, Quality: 0 },
            ..Default::default()
        };
        let c = D3D12_COMPUTE_PIPELINE_STATE_DESC { pRootSignature: std::mem::transmute_copy(&root), CS: cs, ..Default::default() };
        // Zeroed first: the padding between a type and eight-byte data is ours to set.
        let mut s: Mesh = std::mem::zeroed();
        s.root.0 = D3D12_PIPELINE_STATE_SUBOBJECT_TYPE_ROOT_SIGNATURE;
        s.root.1 = root.as_raw();
        s.ms = Sub(D3D12_PIPELINE_STATE_SUBOBJECT_TYPE_MS, ms);
        s.ps = Sub(D3D12_PIPELINE_STATE_SUBOBJECT_TYPE_PS, ps);
        s.targets = Sub(D3D12_PIPELINE_STATE_SUBOBJECT_TYPE_RENDER_TARGET_FORMATS, formats);
        s.dsv = Sub(D3D12_PIPELINE_STATE_SUBOBJECT_TYPE_DEPTH_STENCIL_FORMAT, DXGI_FORMAT_UNKNOWN);
        s.samples = Sub(D3D12_PIPELINE_STATE_SUBOBJECT_TYPE_SAMPLE_DESC, DXGI_SAMPLE_DESC { Count: 1, Quality: 0 });
        let m = D3D12_PIPELINE_STATE_STREAM_DESC { SizeInBytes: size_of::<Mesh>(), pPipelineStateSubobjectStream: (&raw const s).cast_mut().cast() };

        let gso: ID3D12PipelineState = device.CreateGraphicsPipelineState(&g).unwrap();
        let cso: ID3D12PipelineState = device.CreateComputePipelineState(&c).unwrap();
        let mso: ID3D12PipelineState = mesh_device.CreatePipelineState(&m).unwrap();

        let library: ID3D12PipelineLibrary1 = {
            let made: windows::core::Result<ID3D12PipelineLibrary> = mesh_device.CreatePipelineLibrary(&[]);
            made.unwrap().cast().unwrap()
        };
        let n = |s: &str| PCWSTR(HSTRING::from(s).as_ptr());
        println!("store:");
        println!("  graphics: {:?}", library.StorePipeline(n("g"), &gso));
        println!("  compute:  {:?}", library.StorePipeline(n("c"), &cso));
        println!("  mesh:     {:?}", library.StorePipeline(n("m"), &mso));
        println!("load, same library, the descriptions that created them:");
        report("graphics", library.LoadGraphicsPipeline(n("g"), &g));
        report("compute", library.LoadComputePipeline(n("c"), &c));
        report("mesh", library.LoadPipeline(n("m"), &m));
        drain(&device);

        println!("after Serialize, from a library made of the blob:");
        let mut blob = vec![0u8; library.GetSerializedSize()];
        library.Serialize(&mut blob).unwrap();
        let again: ID3D12PipelineLibrary1 = {
            let made: windows::core::Result<ID3D12PipelineLibrary> = mesh_device.CreatePipelineLibrary(&blob);
            made.unwrap().cast().unwrap()
        };
        report("graphics", again.LoadGraphicsPipeline(n("g"), &g));
        report("compute", again.LoadComputePipeline(n("c"), &c));
        report("mesh", again.LoadPipeline(n("m"), &m));
        drain(&device);
    }
}

/* The shaders, compiled with dxc:
mesh.hlsl   [ms_6_5]  struct Vtx { float4 pos : SV_Position; };
                      [outputtopology("triangle")] [numthreads(1, 1, 1)]

vs.hlsl     [vs_6_0]  float4 main(uint id : SV_VertexID) : SV_Position { float2 p = float2((id << 1) & 2, id & 2); return float4(p - 1.0, 0, 1); }
```
