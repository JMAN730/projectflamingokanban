# [Audit & Hardware Census] 26,503 shaders analyzed on D3D12 (RTX 4060 Ti): cutscene fade analysis, 3 isolated hardware blockers, and opcode failure taxonomy

### Environment
- **Target Title:** Grand Theft Auto VI (Xbox Series Scarlett master build v1.0.2.1)
- **Host GPU:** NVIDIA GeForce RTX 4060 Ti 8GB (Ada Lovelace, Driver 572.x / 576.x)
- **Host CPU:** Intel Core i5-10400F (6C/12T)
- **OS:** Windows 11 x64 (24H2)
- **Base Commit:** `14c15be` (`dev-next`)

---

### 1. Executive Summary & Runtime Baseline

Earlier community reports (such as #496) identified crashes or black screens at the transition to the first cutscene. Running telemetry directly on clean baseline `14c15be` (without experimental debug layers or pipeline-skipping flags) reveals:

1. **The Black Frame Transition is an Intentional Fade-Out:**
   - Log line: `WARN victory_gpu::queue: levels after the black frame frame=4402 levels=[252, 252, 251, 250, 249, 0, 0, 0, 0, 0, 0, 0]`
   - This probes maximum pixel luminance over the last 12 presented frames. It represents Rockstar’s intentional loading-screen fade-out curve before Lucia's prison scene. It is not an unhandled exception or an execution fault.
2. **Current Baseline Stability:**
   - With `VICTORY_D3D12_DEBUG=1` removed (eliminating NVIDIA kernel TDR `0x887A0006` caused by Microsoft's validation layer choking on 30+ concurrent command lists), the engine runs locked at **30.1 FPS (33.3 ms/frame, 5.2 ms GPU time)**. Audio, keyboard/gamepad emulation, and subtitles advance continuously.
3. **The 3D Scene Remains Black Because Draws Are Dropped:**
   - Shaders that fail DXIL translation mark the corresponding draw/dispatch as `is_skipped` in `draw.rs`. Without compiled geometry and lighting pipelines, the presented image stays at luminance 0.

---

### 2. Autonomous Hardware Shader Census (`shaders.rpf`)

Running the offline compiler and driver pipeline builder (`victory translate --validate --pipelines "shaders.rpf"`) across the full package yielded **10,977 CPU-seconds** of continuous validation and physical PSO creation on the host RTX 4060 Ti:

- **Total Containers Discovered:** 26,503 (614 duplicates skipped)
- **Lowered to IR:** 26,084 of 26,084 (40,601,701 instructions)
- **Successfully Emitted DXIL & Validated by Driver:** **Over 22,000 shaders compiled directly into native D3D12 hardware PSOs without driver removal or kernel faults.**

---

### 3. The 3 Hardware & Specification Blockers

The full hardware run cleanly separated compiler limitations, Microsoft DXIL validator restrictions, and NVIDIA driver parameter rejections:

#### A. Mesh Shader Output Payload Limit Exceeded (53 programs)
- **Error:** `validator: Function: main: error: For shader 'main', vertex plus primitive output size is greater than 32768.`
- **Example:** `MS_VS_PedTransformTransmissionFire_52f61330_Wrapped Ms` (offset `0x11a9ba5`)
- **Cause:** Microsoft DXIL enforces a strict 32 KiB (32,768 bytes) per-threadgroup limit on combined vertex + primitive outputs. On Scarlett’s unified physical memory, Rockstar exceeded this cap in character/fire mesh shaders.
- **Fix:** PR #586 (staging `GS_ALLOC_REQ` counts in group-shared LDS memory and unifying `SetMeshOutputCounts` at the postdominator join).

#### B. Driver PSO Rejection: `E_INVALIDARG 0x80070057` (328 compute programs)
- **Error:** `pipeline: Parâmetro incorreto (0x80070057)` on `CreateComputePipelineState`
- **Example:** `cascadeshadows_classify:CS_ShadowUnifiedClearRaster_6bcdd348_Wrapped Cs` (offset `0xbeb3b20`)
- **Cause:** Cascade shadow map clearing and classification shaders. The generated host root signature exceeds the 64-DWORD root parameter budget or maps root constants/views into overlapping or unsupported PC register spaces.
- **Fix:** PR #493 / PR #710 (root SRV table bounding and root parameter consolidation).

#### C. Untracked Indirect Descriptor Addressing (298 programs)
- **Error:** `resources: a descriptor neither loaded nor built`
- **Example:** `VS_TransformSkin_VfxVBuffer_AlphaClip_5fd4397c_Wrapped Vs` (offset `0x49c1fc0`)
- **Cause:** Vertex skinning shaders where buffer views are passed via indirect SGPRs without tracing back to a statically enumerated table slot.

---

### 4. Taxonomy of the Remaining Translation Blockers (~2,900 programs)

The remaining dropped shaders fall into 5 distinct architectural clusters in `crates/victory-shader`:

| Cluster | Count | Example Shader | Technical Solution |
| :--- | :--- | :--- | :--- |
| **64-bit Image / UAV Atomics** | 653 | `PS_Cable_AlphaPrepass_c1b6bb00_Wrapped Ps` | Map 64-bit atomic opcodes (`image_atomic_add`, etc.) to DXIL intrinsic `dx.op.atomicBinOp` using `i64` operands. |
| **Lane Masks Read as Scalar Data** | 1,114 | `MS_VS_TransformFire_e74ae427_Wrapped Ms` | Lower scalar reads of the hardware `EXEC` register to DXIL `WaveActiveBallot`. |
| **Dynamic-Stride Structured Buffers** | 117 | `prop_batch_2lyr_cutout_hbb:CS_RaytracingResolve` | Fallback to `ByteAddressBuffer` (raw buffer) with byte-offset addressing (`byte = index * stride`). |
| **Barycentric Interpolations & Packed f16** | 395 | `PS_ShadowRender_CSM_ST_DITHER2_LINEAR_8d576233` | Connect computed barycentrics to DXIL `dx.op.evalInterpolated` (SM 6.1+). |
| **Sub-Dword LDS & Numeric Casts** | 55 | `TAA2:CS_TAA2_PrepareFrameStats_f3fe77a8` | PR #571 (`ds_read/write` 8/16-bit + `_d16`), PR #499 (`v_sat_pk_u8_i16`), and `v_cvt_f32_f64`. |

---

### 5. Verified Compiler Patches

In local testing, applying **PR #571** (sub-dword LDS operations) and **PR #499** (`v_sat_pk_u8_i16`) in `crates/victory-shader/src/emit/lower.rs` compiles cleanly in release mode (MSVC 18.8, 26.14s) without touching runtime state or threading locks, successfully recovering 16 critical post-processing compute shaders (including TAA frame stats).
