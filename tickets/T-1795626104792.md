### Comment 1 — @LAKSHYA-cmd-tech — 2026-11-24T09:09:14Z

Confirmed root cause on Windows 11 without active display support:

- When running headless, in virtual machines, under RDP sessions, or on laptop configurations without an active HDR/display route, Windows Power Management returns `ERROR_NOT_SUPPORTED` (`0x80070032` / `-2147024846`) from `PowerSetRequest(request, PowerRequestDisplayRequired)`.
- `PowerCreateRequest(&context)` already successfully creates the power request handle. Since a display sleep deferral is purely a power-saving hint to prevent the monitor from going to sleep while playing, an inability to prevent display sleep should not fail the API call or abort the title.
- Fix: In `crates/victory-hle/src/modules/display.rs:acquire_deferral`, tolerate `ERROR_NOT_SUPPORTED` (`0x80070032`), keep the valid request handle, and return `S_OK`.

Tested with all 94 unit tests passing in `crates/victory-hle`, clippy clean, and asset policy ok. Available on fork branch `fix/display-deferral-headless-support`.
