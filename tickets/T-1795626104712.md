## Original body


### Setup
- CPU: Intel Core i7-9700F (Coffee Lake, no CLWB/CLZERO/MONITORX/SSE4a)
- GPU: NVIDIA GeForce RTX 5070 Ti, Windows 11
- VIctory: main as of 2026-11-23, release build

### 1. Intel CPUs: missing Zen 2 instructions (patch attached)
The title faults with `0xC000001D` on instructions Intel lacks. I added a vectored handler in `victory-loader` (`cpucompat.rs`, installed from `report_crashes()`, ahead of the crash reporter):

| Instruction | Sites hit (RVA) | Handling |
|---|---|---|
| `CLWB m8` | 0x4ecc84a, 0x4e4b680, 0x532f1b0/1f0/230 | rewritten once to `CLFLUSHOPT` (or DS:`CLFLUSH`) |
| `CLZERO` | 0x4e8aa70 (zeroing loop) | emulated; the `clzero/add/cmp/jb` loop runs in one go |
| `MONITORX` / `MWAITX` | 0x4fb0bd7 / 0x4fb0c00 | rewritten once to 3-byte NOP / `PAUSE; NOP` |
| `INSERTQ` (SSE4a, imm form) | 0x2e7ff1, 0x455bac7 | site patched to `jmp` into a near stub (shifts on rax/rcx, flags saved); `EXTRQ` too |

Unhandled illegal instructions are logged with their bytes. The INSERTQ/EXTRQ stubs were checked natively against a reference for every len/idx. With this, the title boots to the language screen at 30 fps on the i7-9700F.

### 2. NVIDIA: GPU hang (TDR) at the language screen
With `VICTORY_D3D12_DEBUG=1` + `VICTORY_D3D12_DRED=1` (diag build):
- `DXGI_ERROR_DEVICE_HUNG`, list stopped at command 60 of 90 (op 4), commands 59..87 between barriers, no markers
- preceded by `slow host submission ms=508..534`
- pipelines in the hung submission (both runs): `compute 052a2316a03b9ba1`, `vertex 0602c2384acbb3b2/pixel a78d088fa55aa495`, `vertex 58d926085fca4999/pixel edc1cad8ffb79bc9`, `vertex dfafaf385b2f94e8/pixel 06295fb1d1aefb78`
- still hangs with `TdrDelay=10`, so it looks like a non-terminating loop rather than a slow shader. My guess is wave64-dependent code running with 32-lane waves on NVIDIA.

Other warnings on NVIDIA:
- `host view heap capped at 1000000 ... count=1245184`
- `no host texture`: 2560x1440 `format 86` (B5G5R5A1) flags 5 (RT|UAV), and `format 115` (B4G4R4A4) flags 1 (RT); these are unsupported RT/UAV formats on NVIDIA.
- WARP (`VICTORY_D3D12_WARP=1`) also fails: `0x887A0005` after ~35 s, before the language screen.

Happy to run any test build.
