## Original body

### Summary
Implements 4 missing standard `ID3D12GraphicsCommandList` vtable slots in `crates/victory-gpu/src/list.rs` across both `LIST_FUNCTIONS` and `NEWER_LIST_FUNCTIONS`:
- **Slot `31` (`0xf8`)**: `SetPredication`
- **Slot `56` (`0x1c0`)**: `SetMarker`
- **Slot `57` (`0x1c8`)**: `BeginEvent`
- **Slot `58` (`0x1d0`)**: `EndEvent`

Because external PR creation is currently restricted (`collaborators_only`), the CI-green branch is ready on my fork for cherry-pick / review:
- **Branch**: `geiyiliyabumo/VIctory@feat/list-predication-and-markers`
- **Commit**: `geiyiliyabumo/VIctory@a74fe6b` (based on `main` `ffe310e`)

### Changes (`crates/victory-gpu/src/list.rs`)
- **`set_predication` (`0xf8`)**:
  - Null buffer cleanly disables predication (`SetPredication(None, 0, D3D12_PREDICATION_OP_EQUAL_ZERO)`).
  - Non-null buffer validates `operation` (`0` = `EQUAL_ZERO`, `1` = `NOT_EQUAL_ZERO`), 8-byte `offset` alignment, and `buffer_range(buffer, offset, 8)`.
  - For host-backed resources, ensures `D3D12_RESOURCE_STATE_PREDICATION` before forwarding; for CPU-backed guest buffers, stages the 8-byte predicate via a list-owned `host.upload(device, 8)` filled at submission (`host.defer_fill`) so deferred guest writes are observed.
- **`set_marker` (`0x1c0`), `begin_event` (`0x1c8`), `end_event` (`0x1d0`)**:
  - Normalizes null/zero-size payloads to `(None, 0)` before forwarding to host D3D12 and records `diagnostics` op notes.
- **Tests**:
  - `list::tests::predication_and_marker_slots_are_stable` (verifies all 4 slots in both `LIST_FUNCTIONS` and `NEWER_LIST_FUNCTIONS`).
  - `list::tests::set_predication_and_markers_execute_on_gpu` (exercises markers/events + `EQUAL_ZERO` predication skipping on `0`, executing on `1`, and disabling with `null`, verifying exact GPU readback bytes and zero final refcounts).

Binding that shadow directly through D3D12 let the dispatch write 0x22; a zero predicate preserved the 0x11 sentinel. With the same nonzero GPU value, the guest SetPredication path preserved 0x11. For an ordinary buffer it stages the CPU bytes at submission, before the GPU executes the producing command.

A second synthetic comparison used a guest typed UAV clear as the producer, on a stack with #785’s written-shadow lookup.
