## Original body

`cargo test -p victory-shader` does not compile on `main` (`cf0bb43`):

```
error[E0061]: this function takes 2 arguments but 1 argument was supplied
    --> crates\victory-shader\src\emit\lower.rs:6954:13
6954 |             lowers(&words).unwrap();
     |             ^^^^^^-------- argument #2 of type `u32` is missing
```

Two merges crossed. #432 (`25b0f88`) gave the test helper `lowers()` an `rsrc2` argument and updated the callers it knew about. #117 (`3c86053`) added the `s_bitcmp` test with a call of the old form. The helper used `rsrc2: 0` before, so the fix is one argument:

```diff
-            lowers(&words).unwrap();
+            lowers(&words, 0).unwrap();
```

With it (cross-built with `cargo xwin`, run under Wine), `cargo xwin test -p victory-shader` gives 76 passed and 12 failed. The 12 are all `emit::valu_tests::*`, which need an SM 6.6 device. Clippy is clean.

I had the fix ready as a PR (branch `BastienRodz:fix/bitcmp-test-lowers-arg`, commit `4628759`), but PR creation is now limited to collaborators, so I'm filing it here instead. It is also a separate commit in #568, which needs it to run the shader tests after rebasing.

No game data used. AI-assisted (Claude Code).
