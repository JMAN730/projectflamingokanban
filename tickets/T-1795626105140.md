### Summary
Testing across AMD Radeon RX 6600 (RDNA2) and Microsoft WARP isolates two distinct blockers:

1. **RX 6600 Hardware Fault (`0x887A0006` / `0x887A0004`):** Execution consistently hits a deterministic GPU page fault at `0x1f51d0000`—an exact **`+0xF0000000`** offset from the view heap base (`0x1051d0000`, slot `125,829,120`)—between frames `1092` and `1534`. `VICTORY_SKIP_PIPELINES` A/B testing confirms this is a systemic descriptor-heap issue across disjoint compute batches rather than a single shader.
2. **WARP Bypass & Missing Textures In-Game:** Running lean on `VICTORY_D3D12_WARP=1` (no D3D12 Debug Layer) completely bypasses the RX 6600 device removal and loads in-game (prison scene with Lucia), remaining stable for ~17 minutes until manually closed. However, geometry renders with **no textures** following a burst of `victory_hle::modules::dstorage` destination physical-page write failures.

### RX 6600-Specific Findings

#### 1. Deterministic View-Heap Page Fault (`0x1f51d0000` = `view_heap_base + 0xF0000000`)
- Across three separate DRED captures (frames `1327`, `1500`, `1534`), the RX 6600 faults at the exact same VA `0x1f51d0000` (`0xed200000` past the end of view heap `0x1051d0000+0x2e00000`, slot `125,829,120`).
- Skipping the 7 compute shaders from the frame `1327` batch (`ce684a9201818f3f`, `8bb272e763f76148`, `02384a60fda6f2d0`, `339d476c267c03c7`, `42683eebec081520`, `82849f7a614208eb`, `9afd549c4f530901`) still hits `0x1f51d0000` at frame `1500` on a 1-list batch (`ebe4e53f031f5249`, `a133bf0a24aff410`, `4c0ac499ad613809`). Skipping `ebe4e53f031f5249` still hits `0x1f51d0000` at frame `1534` on the 7-shader batch.
- Every faulting batch contains dispatches with `u5` bound to `[heap ...: null]`. WARP silently returns zero on out-of-bounds descriptor reads and continues to in-game, whereas RDNA2 faults on the unmapped VA and triggers TDR.

#### 2. Persistent UAV vs. Vertex Buffer State Mismatch (`id=527` / `id=538`)
- Reproduces across default copy mode, `VICTORY_COPY_MODE=none`, and WARP on `title buffer +0xae00000` (~182 MB): the resource stays in `D3D12_RESOURCE_STATE_UNORDERED_ACCESS (0x8)` while `IASetVertexBuffers` (`id=538`) and `ResourceBarrier` (`id=527`) expect `D3D12_RESOURCE_STATE_VERTEX_AND_CONSTANT_BUFFER (0x1)`.

#### 3. GBV SRV Dimension Mismatch & PSO Cache Collision
- GBV flags **7 consecutive draws** with `GPU-BASED VALIDATION: Draw, SRV resource dimensions differs from that expected by shader` right before frame `1343` drops to black (potentially related to `null_view` in `crates/victory-gpu/src/descriptor/host.rs:1336` defaulting unknown slots to a 2D null view).
- Debug layer also logs a PSO library collision (`id=972` desc mismatch / `id=970` already exists) for `3f47d74d0f98c291c8d8324a3ac75c96`.

### WARP In-Game / Missing Textures Findings

Once past the RX 6600 fault on lean WARP, the prison scene loads with untextured geometry. Logs show:
1. **`dstorage` Destination Page-Write Failures:** Dozens of consecutive streaming requests fail across 1–2 page targets (`len=4096` to `131072`).
2. **Unimplemented GPU Ops:**
   - `victory_gpu::list: texture to buffer copies not implemented`
   - `victory_gpu::object: method not implemented object="device" slot=0x1c8 caller="+0x247757e"`
   - `buffer view empty or past its host copy` (`first=0 count=0 element=4`) and `unordered buffer view empty or past its host copy` (`first=2717528 count=0 element=16`).
3. **Refused PSO & Dropped Shaders:**
   - Host mesh pipeline refused (`E_INVALIDARG 0x80070057`): `[mesh f5e50eb2108c425b, pixel ce3f0432a08f1d35]`.
   - Dropped pixel shaders: `barycentrics read directly` (`98bd9f9ae5f9c7e3`, `5067d502a1b4ffb4`), `a descriptor read only as data` (`2fd01fca16993001`, `6b6db9f1a526daeb`, `7d0f14ce44746d7e`).
   - Dropped compute shaders: `descriptor chosen by control flow` (`39f0e9aeb156a61c`), `descriptor neither loaded nor built` (`2da4beb386509b77`, `aab1b3c7248ee5de`), `v_cvt_f32_f64` (`5dc3b25986622949`, `6f225b641c5b0708`), `v_permlanex16_b32` (`a929109552ce1e84`), and lane-mask/data join errors.
