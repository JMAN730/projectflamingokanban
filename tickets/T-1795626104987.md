### Comment 2 — @heromike405-arch — 2026-11-24T15:17:40Z

Cross-check on Windows 11 (build 26100) with an RTX 5060 Laptop GPU and Radeon 610M. I used a synthetic static sampler with `D3D12SerializeVersionedRootSignature`, root-signature version 1.1, and the same flags as `emit/host.rs`.

- The raw biases from `0x2000` (`-32`) and `0x1FFF` (`31.99609375`) returned `E_INVALIDARG` at serialization.
- The exact values used by #326 (`-16.0` and `15.99`) serialized successfully and passed `CreateRootSignature` on both hardware adapters.

The two extreme-value assertions in `mip_lod_bias_decodes_signed_14bit_fixed_point_extremes` currently call `StaticSampler::from_words` directly. #326 clamps in that same function, so those assertions would fail if both changes landed as written. If the clamp stays there, updating the two expectations would cover the value sent to D3D12. Testing raw sign extension would then require a separate raw decode step.
