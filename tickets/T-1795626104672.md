## Question

Every NVIDIA card runs 32-lane waves. The translator declares 64 for console compute programs that need it, the host refuses about a hundred pipelines, and the title never submits the world pass. Which approach does this fork adopt as its base?

- **Console flow:** one console wave runs as the console ran it, exact under divergence; refuses groups of more than 64 threads.
- **Emulate over narrower waves:** spread one console wave over several host waves with lane remapping; covers more programs, with reported regressions and an inexact fast path.
- **Declare 32 where provably safe** (whole-wave reductions over at most 32 threads), and refuse the rest.
- **Refuse** all of them and accept the missing passes.

Also to settle: which mode is the default on a 32-lane host, and whether 64-lane hosts are left untouched.

## Context

Fork pull request #26 implements the third option for a narrow case. The wave rules research and the inventory say what is legal and what is already on `main`.
