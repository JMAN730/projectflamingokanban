## Original body

Title: Verified FidelityFX CAS PC replacements: 8 fp32 variants, bit-exact golden model (ffx-kit)

Hi! We built a small verification kit that may help with the FidelityFX side of the shader pipeline.

What it does:
- Compiles official AMD FidelityFX-CAS sources (MIT) with DXC to SPIR-V.
- Runs them on a real GPU via Vulkan (wgpu-py).
- Verifies every output against a CPU golden model that mirrors AMD's exact arithmetic:
  APrxLoRcpF1 / APrxMedRcpF1 / APrxLoSqrtF1 bit tricks, the green-channel weight path,
  and D3D saturate(NaN)=0 semantics.

Results (2026-11-24, RTX 4070 Ti, Vulkan, DXC 1.9.2609.5):
- 8/8 fp32 sharpen-only variants (CAS_BETTER_DIAGONALS x CAS_GO_SLOWER x CAS_SLOW): PASS
- 144 matrix tests + 3840x2160: worst max abs diff 4.77e-07 (a few fp32 ULPs)
- manifest.json with per-variant SHA-256 and per-test diffs

Why this may matter: a naive "mathematically correct" reference disagrees with AMD's
fast-math paths by up to ~8.5% of signal, so checking translated FidelityFX output against
exact math produces false failures. This kit reproduces the intended approximations.

Scope / honesty:
- fp32 sharpen-only today; fp16 packed (CasFilterH) and scaling next.
- No game files, keys or console binaries - only official open sources.
- Verified on one GPU so far; reproduction is 4 commands in the README.

Repo: https://github.com/Cobrall/ffx-kit
Happy to adapt the harness to Leonida's pipeline or open PRs if useful.
