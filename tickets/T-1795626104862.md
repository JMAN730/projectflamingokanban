## Original body

Fix ready on a branch: [pablogonz12:gpu-no-blend-on-integer-targets](https://github.com/Marvisak/VIctory/compare/main...pablogonz12:VIctory:gpu-no-blend-on-integer-targets) (one commit `169efcb` on `main` `ffe310e`, +122/-2, `pipeline/host.rs` only). GitHub doesn't let me open a PR on this repo, so here it is as an issue; happy to open the PR if that becomes possible.

## What

The title leaves blending enabled on integer render targets. The console ignores it there, but D3D12 does not allow it, and vkd3d-proton refuses the whole pipeline:

```
err:vkd3d-proton:d3d12_pipeline_state_validate_blend_state: Enabling blending on RT 2 with format DXGI_FORMAT_R8_UINT, but using integer format is not supported.
WARN victory_gpu::pipeline::host: host mesh pipeline refused error=Invalid parameter. (0x80070057) shaders=[mesh f5e50eb2108c425b, pixel ce3f0432a08f1d35]
```

That is a world mesh pipeline, so its draws were dropped on Linux.

`host_blend` in `pipeline/host.rs` builds the blend description the host pipeline gets (both the graphics and the mesh path): blending off on every render target in use whose format is `*_UINT`/`*_SINT`. When the title's description has `IndependentBlendEnable` off, each target gets a copy of target 0's state first, so the other targets keep blending as before. Any state without integer blending is passed through unchanged.

## Tested

- RX 9070 XT, RADV (Mesa 26.3.1), CachyOS, GE-Proton11-14 with vkd3d-proton master (`30b0eb9`), diagnostics build, into the world:
  - before: the pipeline above refused (1 refusal, the vkd3d-proton error above);
  - after: the same pipeline is created; no refusal and no integer-blend error in the run.
- New tests `integer_targets_do_not_blend` and `blend_states_without_integer_blending_are_kept`.
- `cargo test -p victory-gpu --lib`: 52 passed, 0 failed (run under Wine).
- `cargo clippy -p victory-gpu --all-targets --locked -- -D warnings`: clean.

## Not tested

- Native Windows. Drivers there seem to accept the state; this only changes pipelines that blend into an integer target, where blending has no effect anyway.
