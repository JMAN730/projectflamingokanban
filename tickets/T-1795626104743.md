### Comment 5 — @zivyn — 2026-11-24T02:47:16Z

**The bottleneck isn't the GPU.**

- Shader translation and tests run on the CPU only. Translating the game's full shader corpus (about 26,000 shaders) keeps every CPU thread busy while the GPU sits idle.
- Building the Rust code depends on the CPU and the disk.
- The coding agents run in the cloud. Locally they only use CPU and disk.
- Running the game: the slowness in the open world (0.5 to 1.8 s per frame on the maintainer's machine) comes from the translation layer itself. It copies title memory, compiles shaders the first time they appear, and drops draws whose shaders it can't translate yet. A faster GPU doesn't change any of that.
