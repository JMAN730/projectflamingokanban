## Original body

Shaders: 16-bit vertex inputs are refused

`load_input` returns "a 16-bit input" for a signature element with `half` set (the fetch shader's attributes). Pixel interpolation already unpacks 16-bit inputs to 32-bit host values; the vertex path does not.

The host signature already declares these 32-bit (`SigElement.half`). The fetch result on the console is the 16-bit value in the low half of the VGPR (one per dword). Packed (two per dword) is a later slice: `VsInput` has no pack flags.

Synthetic test, no game files.
