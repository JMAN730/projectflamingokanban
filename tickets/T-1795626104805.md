## Original body

## Problem
On D3D12, shader-visible sampler descriptor heaps are strictly limited to 2048 descriptors (`D3D12_MAX_SHADER_VISIBLE_SAMPLER_HEAP_SIZE = 2048`) across all resource binding tiers.

When a title allocates a shader-visible sampler descriptor heap with `count > 2048` (e.g. 4096 or more as a block allocation):
1. `HostHeap::new(true, count)` invoked `make(count)` which failed with `E_INVALIDARG`.
2. The fallback capping logic was guarded by `!sampler`, causing sampler heaps > 2048 to fall into the error branch and return `None`.
3. `Descriptor::host()` cached `None` in `OnceLock`.
4. `draw::State::bind()` filtered descriptor heaps via `filter_map(|&h| heap(h).host())`, completely dropping the sampler heap from `SetDescriptorHeaps()`.
5. In `HostHeap::fill_null()`, a hardcoded `BLOCK = 1 << 16` (65,536) CPU descriptor heap was created to seed null descriptors, which also failed for sampler heaps.
6. In `draw::State::tables()`, any table extending past `host.count()` was unconditionally added to `fresh` (dynamic table creation), which is specific to 32-byte view descriptors and always failed for sampler tables (`host.dynamic()` returns `None` for samplers).

Fixes #65. Refs #21.

## Solution
1. **HostHeap Capping (`crates/victory-gpu/src/descriptor/host.rs`)**:
   - Defined `PORTABLE_SAMPLERS: u32 = 2048`.
   - In `HostHeap::new()`, when `sampler && requested > PORTABLE_SAMPLERS`, capped host heap creation to `PORTABLE_SAMPLERS` (2048) with a descriptive `tracing::warn!`, mirroring the `PORTABLE_VIEWS` behavior.
2. **Null Fill Bounding (`crates/victory-gpu/src/descriptor/host.rs`)**:
   - In `fill_null()`, capped temporary block allocation to `let block_size = BLOCK.min(total)`. For sampler heaps, `block_size` is at most 2048, allowing successful creation and initialization of null point samplers.
3. **Table Remap Guard (`crates/victory-gpu/src/draw.rs`)**:
   - In `State::tables()`, guarded `fresh.push(u.slot)` with `!heap.samplers() && index >= host.count()` so sampler tables are not misrouted to the view dynamic-slot allocator.
4. **Synthetic Regression Tests**:
   - Added `descriptor::host::tests::sampler_heap_larger_than_2048_is_capped` verifying that `HostHeap::new(true, 4096)` creates a valid heap of count 2048 and maintains device health.
   - Added `descriptor::tests::sampler_heap_larger_than_2048_creates_host_heap` verifying end-to-end descriptor heap creation and host heap association.
