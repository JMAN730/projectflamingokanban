## Original body

Every per-program measurement on this tracker has been made so far with a script of the reporter's own (#736, #233, #201, #459). `victory compare <before> <after>` reads two `translate --list` outputs and gives that answer without one:

```
victory translate --validate --pipelines --list > before.txt    # main
victory translate --validate --pipelines --list > after.txt     # the change
victory compare before.txt after.txt
```

It prints:

- each run's pipelines and validations (the runs' own totals), then what was gained and lost;
- how many pipelines come from modules the validator refuses, and how many of the gained ones do (the "5 of the 98" question on #233);
- every program that ends differently, counted by its reason before and after;
- every loss, with both reasons.

The key is the file's name, offset, record and stage, so copies of the title in other folders compare. A program a run stopped earlier counts as not made for that run's checks, so "pipeline created before, refused by the translator now" is a loss.
