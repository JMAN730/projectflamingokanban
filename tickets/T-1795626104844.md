## Original body

Hey everyone,

Would you be interested in setting up a self-hosted Git platform using Gitea or Forgejo?

A friend and I could potentially provide the hosting infrastructure for this.

The idea would be to:

- Automatically synchronize public repositories from GitHub.
- Maintain independent backups of the source code and commit history.
- Preserve authorized project data, issues, pull requests and releases where possible.
- Provide an independent development platform while keeping GitHub available for community contributions.
- Reduce the risk of losing development work if a repository becomes unavailable.

Blender already uses a self-hosted Gitea instance for its development infrastructure: https://projects.blender.org/blender/blender

This could be a complementary platform rather than a replacement for GitHub, with the agreement of the respective project maintainers.

Let me know what you think!
