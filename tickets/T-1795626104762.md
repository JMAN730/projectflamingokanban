### Comment 2 — @Rooseveltfj — 2026-11-24T04:32:45Z

Heads up first: VIctory isn't playable yet. Per the README status, it boots, runs the menus and loads into the world, but in-world rendering fails (black screen, and the GPU can hang within seconds). Right now it's mostly for testing/dev.

If you still want to try it:

**Requirements**
- Windows 10/11 x64
- CPU with AVX2 (some Intel users are hitting crashes, see #6 and #7)
- Direct3D 12 GPU with Shader Model 6.6 + mesh shaders
- Rust (version is pinned in `rust-toolchain.toml`, rustup picks it up automatically)
- Your own Xbox Series X|S copy of the game files. They're not in the repo and can't be shared here.

**Build & run**
```
git clone https://github.com/Marvisak/VIctory
cd VIctory
cargo xtask install-hooks
copy victory.example.toml victory.toml   # edit the paths (keep them outside the repo)
cargo test --workspace
cargo run -p victory -- config           # checks your paths
cargo build --release -p victory
target\release\victory.exe run <game dir>\<game exe> --execute
```

If your GPU hangs when entering the world, set `VICTORY_D3D12_WARP=1` to use the software adapter for diagnostics. Saves, settings and `crashes.log` go to `%LOCALAPPDATA%\victory\data`, so attach `crashes.log` if you open an issue.

Also, the README only covers building from source. Be careful with any prebuilt "GTA 6 PC" .exe floating around on other sites, those are usually malware.
