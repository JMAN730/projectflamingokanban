## Original body

CI was added at 08:55 and only runs when an author pushes again, so most open PRs have never been through it. I ran its three steps (`ci.yml`: Clippy, Clippy with `--all-features`, `cargo test --workspace`, all `--locked`) on each of the **291 open, non-draft PRs that GitHub shows as mergeable and that had no CI run**, each merged onto `main` `ffe310e`.

**267 pass all three steps. 24 fail.** Nine of those are the `resource::track` calls already listed in #801 (#101, #142, #165, #166, #171, #200, #457, #694, #705). The other 15:

**Build breaks from other signature changes on `main`** (no text conflict, so GitHub shows them as mergeable):

- **`lowers` in `emit/lower.rs`'s tests now takes `rsrc2: u32`** (since `25b0f888`, "Test probe: compare direct and joined reads of a shader timestamp"). These PRs add calls with one argument, `error[E0061]: this function takes 2 arguments but 1 argument was supplied`:
  - #120, #148, #308, #608 (#608 also has an unused import, `half_shift`)
- **#420** adds a field, `root_indexed_views`, to `HostShader`. `main`'s new `emit/waterfall_tests.rs` (from `6638098` and `ffe310e`) builds a `HostShader` without it: `error[E0063]: missing field root_indexed_views` at `waterfall_tests.rs:77`.

**Breaks in the PR itself:**

- **#638** changes `crates/victory-gpu/Cargo.toml` but not `Cargo.lock`, so every `--locked` step fails: `cannot update the lock file ... because --locked was passed`.
- **#241** uses `std::os::unix` (and `FileType::is_fifo` / `is_socket`) in `crates/victory-core/src/config.rs` without a `cfg(unix)`, so it doesn't build on Windows, where CI runs.

**Clippy `-D warnings`, in lines the PR adds or changes** (the build and tests pass):

| PR | Lint | Where |
|---|---|---|
| #202 | `undocumented_unsafe_blocks` | `victory-gpu/src/host.rs:1378` |
| #502 | `undocumented_unsafe_blocks` (2) | `victory-gpu/src/list.rs:1464` |
| #378 | `collapsible_if` | `apps/victory/src/translate.rs:331` |
| #670 | `collapsible_if` | `victory-loader/src/prepare.rs:173` |
| #512 | manual creation of a dangling pointer (`1 as *const u8`) | `victory-hle/src/modules/kernel.rs:665` |
| #623 | unnecessary cast (`i32` -> `i32`, 3) | `victory-gpu/src/pipeline/host.rs:537` |

**A test the PR adds fails** (build and Clippy pass). Each PR was re-run alone, and `main` alone passes 3 of 3:

- **#436**: `shadow::tests::small_ranges_in_one_page_copy_it_once` fails 3 of 3 runs, at `shadow.rs:579`: `update(page + offset, 16)` returns `65536` where the test expects `0`.
- **#925**: `emit::waterfall_tests::lanes_size_the_entry_their_offset_names_in_the_console_waterfall` fails 3 of 3 full runs, at `waterfall_tests.rs:260`, **on WARP only**. The `hardware` pass on the RTX 5060 matches. On `warp`, every odd lane reads `2.0` where `4.0` (red 2.0 plus height 3 - 1) is expected, so WARP reports a height of 1 for entry 1. The WARP here is the one in Windows 11 26300; a CI runner's WARP may differ.

Setup: NVIDIA GeForce RTX 5060 Laptop GPU (Blackwell), driver 621.24, Windows 11 26300, Rust 1.98.1, PR heads as of 2026-11-24 about 14:10 UTC. The test step failures were re-run alone, one PR at a time. No game files: the test suite only.
