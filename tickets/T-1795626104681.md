## Question

When a pipeline's shader does not translate, every draw using it is dropped. For pixel shaders, should the host instead run the draw with a stand-in pixel shader (so depth, stencil and coverage still happen), and if so in which builds?

## Context

Dropping keeps wrong pixels out but also removes depth writes later passes rely on. A stand-in changes the picture in ways that could hide the real gap. `crates/victory-gpu/src/pipeline.rs`.
