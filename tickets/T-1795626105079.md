## Original body

### Environment
- **OS:** Windows 10/11 x64 (AtlasOS)
- **GPU:** NVIDIA (D3D12 Mesh Shaders supported)
- **Title Build:** `7952987A` (Xbox Series X)
- **VIctory Build:** `diag` profile (`b99f876b74d4a77f03af5f878223b27bd647b5c35a79d5decd9f716504239e93`)

### Summary of Behavior
- Boot, audio (APU/DSP), menus, and loading into `story000` work without crashing or causing a TDR/driver reset on NVIDIA (~0.3–1.4 FPS in world).
- However, the window remains completely black (display triggers HDR even though VIctory logs `HDR mode: disabled (SDR presentation)`).

### Key NVIDIA / D3D12 Issues Found in Logs

#### 1. CBV/SRV/UAV Descriptor Heap Limit (NVIDIA 1,000,000 Tier 1/2 limit)
NVIDIA drivers cap shader-visible `CBV_SRV_UAV` heaps at 1,000,000 descriptors:
```text
WARN victory_gpu::descriptor::host: host view heap capped at 1000000 error=The parameter is incorrect. (0x80070057) count=1245184
```
Once world rendering starts (frame 1756+), this leads to descriptor exhaustion and thousands of dropped draws:
```text
WARN victory_gpu::descriptor::host: no free dynamic descriptor slots: a table is not made n=6
WARN victory_gpu::draw: a draw or dispatch dropped: no dynamic slots for its tables dropped=8192
```

#### 2. Host Texture & View Creation Failures (`0x80070057`)
```text
WARN victory_gpu::resource: no host texture error=The parameter is incorrect. (0x80070057) desc=ResourceDesc { dimension: 3, alignment: 0, width: 2560, height: 1440, depth_or_array_size: 1, mip_levels: 1, format: 86, sample_count: 1, sample_quality: 0, layout: 0, flags: 5 }
WARN victory_gpu::resource: no host texture error=The parameter is incorrect. (0x80070057) desc=ResourceDesc { dimension: 3, alignment: 0, width: 2560, height: 1440, depth_or_array_size: 1, mip_levels: 1, format: 115, sample_count: 1, sample_quality: 0, layout: 0, flags: 1 }
WARN victory_gpu::descriptor::host: view the host does not allow unordered=true format=53 flags=2
```

#### 3. Compute Pipelines Refused by NVIDIA Driver (`0x80070057`)
Multiple translated compute shaders are refused at PSO creation on NVIDIA (`13dfdd3b1136e407`, `88994c3496045f51`, `02384a60fda6f2d0`, `339d476c267c03c7`, `42683eebec081520`, `82849f7a614208eb`, `9afd549c4f530901`, `2fa2f94f560faf39`, `a25ed0e3d4d521ba`, `fa0c0819dc86ca60`, `9e096a1111c6faaa`, `00bcbbf278ee3d9d`, `d3e5b737ea7cc150`, `6336cb3769fc53d7`, `5b2ce592c3a5dd09`, `0e90505eff274aa4`, `1f1fbd86759b3da2`, `e4a9f58e3acfcf7b`, `b96880482a17f632`, `c4183d3cbee28e8e`, `2f03a2df10503cef`, `369cbe906ea72764`, `196bf6114ff3a131`, `660814153af43185`, `df3cf10a274e26ca`, `f8f50ab85e7b10bb`, `c9da71da40af2e28`, `a1f6cdf8874960a9`, `ce2378e5e8711aad`, `754e38ca2378a43e`).
